# 在线方案 B：夜间校准台

## 定位与信息架构

- 定位：适合视频、音频等长时任务的专注型工具站，强调“设备内持续处理”。
- 首页：56–70px 五分类图标轨道 + 聚焦式价值说明 + 工作台预览。
- 工具页：五分类图标轨道 → 当前分类工具抽屉 → 视频主预览 → 右侧参数检查器。
- 文件、预览、运行状态在中央连续阅读；参数始终位于右侧或移动端底部步骤。
- 不新增任务历史、云端队列或后台处理承诺。

## 统一目录规范

- 图标轨依次对应图片工具、PDF 工具、文档工具、音视频工具、OCR 工具；不得设置按功能新旧划分的第六入口。
- 抽屉只显示当前真实分类的工具；“浏览全部分类”打开五列统一目录。
- 桌面抽屉、移动底部“选择工具”、面包屑和首页轨道共用同一分类名称及功能清单。
- 批量适用范围使用细边框“离线批量”标签；标签不改变在线单文件权限，也不构成营销徽章。

## 字体与排版

- 字体：`Microsoft YaHei UI`, `Segoe UI`, system-ui。
- 字阶：12 / 13 / 15 / 18 / 26 / 44px。
- 行高：紧凑元数据 1.35，正文 1.55，标题 1.15。
- 字重：400 / 600 / 700；大标题允许 700，不使用全页超粗字。
- 数字和时长使用等宽数字特性 `font-variant-numeric: tabular-nums`。

## 尺寸与组件

- 间距：4 / 8 / 12 / 16 / 20 / 28 / 40px。
- 圆角：3 / 4 / 7px；避免“满屏圆卡片”。
- 控件高度：38px；移动端 44px。
- 阴影：仅抽屉和对话框使用 `0 20px 56px rgba(0,0,0,.42)`。
- 主按钮：蓝色实底；次按钮：深色描边；取消转换为低饱和红色描边。
- 输入框：`#0E151D`，聚焦时蓝色边框和可见外环。
- 图标：项目现有 `lucide-react`，16px，1.5px 描边；图标轨道必须带可见文本提示或 `aria-label`。

## 状态语言

- 空闲：中央预览区提供唯一导入入口，不显示虚假播放器。
- 已选择：文件摘要与首帧同屏，参数已就绪状态位于预览下方。
- 处理中：蓝色进度条、明确“正在转换视频”、取消入口；不承诺后台继续。
- 成功：结果文件名和本地内存说明，下载为唯一强调按钮。
- 失败：内联红色状态块，保留文件上下文，提供重选与说明。
- 支持作者：深色对话框，二维码保持原素材和足够白色静区。

## 响应式与动效

- `≥1181px`：56px 五分类轨道 + 当前分类抽屉 + 主预览 + 右检查器。
- `821–1180px`：抽屉默认关闭，参数下移。
- `≤820px`：轨道、抽屉、检查器全部移除；使用底部任务导航，工具切换器仍按统一五分类呈现。
- `390px`：单列播放器与状态区；底部导航固定但不遮挡内容，页面预留安全区。
- 动效：按钮 100ms、抽屉 160ms、对话框 220ms；`cubic-bezier(.22,.75,.18,1)`。
- 运行进度只做宽度变化，不做闪烁或无意义发光。

## 实现风险

- 难度：中—高。需要独立深色在线壳、移动端底部步骤和可访问抽屉。
- 风险：深色对比与广告位容易失衡；二维码、原生表单控件、浏览器自动填充需逐项校色。
