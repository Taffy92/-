# 万能格式转换器离线专业版 v2.0.0 安装指南

## 支持系统

- Windows 10 x64
- Windows 11 x64

## 安装

1. 从官网同源下载区获取 v2.0.0 EXE 或 MSI 安装包。
2. 对照下载页检查文件大小和 SHA-256。
3. 普通用户优先使用 EXE；企业或管理员批量部署可使用 MSI。
4. 按安装向导完成安装并启动“万能格式转换器”。

## 试用与授权

1. 首次运行自动开启本机 3 天试用。
2. 试用结束后，软件显示当前设备机器码。
3. 用户可输入管理员签发的离线激活码，或导入 `license.mrx`。
4. 授权在本机校验，不要求登录，也不上传用户处理文件。
