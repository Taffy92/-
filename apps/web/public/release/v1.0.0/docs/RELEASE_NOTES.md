# 万能格式转换器 v1.0.0 发布说明

发布日期：2026-06-12<br>
产品名称：万能格式转换离线专业版<br>
开发者：MR.谢

## 版本概览

万能格式转换器提供在线网页版和 Windows 离线专业版。在线版适合轻量单文件处理；Windows 离线专业版适合断网环境、敏感文件和批量任务。

本版本继续坚持本地处理原则：图片、PDF、Word、Excel、音频、视频和转换结果默认只在当前设备中处理，不上传服务器，不调用云端转换 API。

## 在线版能力

1. 图片裁切。
2. 尺寸调整。
3. 添加水印。
4. 图片压缩。
5. PDF 转图片。
6. Word 转图片。
7. Excel 转图片。
8. 音频格式转换。
9. 视频格式转换。
10. 视频提取音频。

在线版只支持轻量单文件或少量文件处理。批量处理入口会提示下载 Windows 离线专业版。

## Windows 离线专业版能力

1. 白色苹果风格本地工作台，选择文件区域同时承担预览功能，大号橙色选择文件按钮支持单选和多选。
2. 多文件任务使用缩略图平铺预览，PDF、Word、Excel 显示第一页内容，预览卡片只保留文件名和缩略图。
3. 批量导入跟随当前转换工具。
4. 图片尺寸调整、加水印和压缩批量队列，图片压缩目标大小支持 500KB、200KB、100KB、50KB、25KB。
5. PDF、Word、Excel 批量转图片。
6. 音频、视频批量转换和视频批量提取音频。
7. 批量任务和多页文档结果保存为本地文件夹，不生成 ZIP 或 7Z。
8. 输出目录选择、清空任务、任务取消和下载结果。
9. 图片、文档、视频和音频本地预览。
10. 页脚只保留本地隐私提示和开发者信息。

## 本地处理和隐私

1. 文件内容不上传服务器。
2. 转换结果不上传服务器。
3. 批量任务状态仅在本机工作台展示。
4. 输出结果由用户主动下载或保存到本地目录。
5. 授权只控制桌面端继续使用，不接触用户处理文件。
6. 广告脚本不会接收 File、Blob、ArrayBuffer、Canvas 或转换结果。

## WebView2 离线安装支持

Windows 离线专业版安装包已配置 WebView2 Evergreen Standalone Installer。目标电脑没有 WebView2 Runtime 且完全断网时，安装包仍可使用本地内置安装器完成运行环境安装。

## sidecar FFmpeg 低风险格式优先

离线专业版仍保留 FFmpeg WASM 回退能力。在 sidecar 校验通过、用户未关闭该选项、输入文件有本地路径且输出目录为本地目录时，以下低风险格式优先使用本地 sidecar FFmpeg：

1. WAV 转 FLAC。
2. MP4 转 WebM。
3. ffprobe 媒体信息读取。

以下格式仍使用 FFmpeg WASM，不属于 sidecar 正式默认范围：

1. MP3 输出。
2. AAC / M4A 输出。
3. MP4 / H.264 输出。
4. MOV 输出。
5. AVI 输出。
6. MKV 输出。
7. 视频提取音频到 MP3 / AAC / M4A。

## 已知限制

1. 在线版不提供批量处理能力。
2. 在线版大文件处理受浏览器内存和设备性能影响。
3. 离线专业版未做代码签名时，Windows Defender 或 SmartScreen 可能出现提示。
4. BtbN FFmpeg 候选仍未完成商业许可证最终复核，不应宣传为已完成最终商业授权审查。
5. MP3、AAC/M4A、MP4/H.264 等格式在商业发布前仍建议做许可证、专利、平台和地区复核。
