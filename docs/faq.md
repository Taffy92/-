# 常见问题

## 文件会上传服务器吗？

不会。核心处理逻辑在浏览器本地或离线程序本地运行，用户图片、PDF、Word、Excel、音频、视频和转换结果不会上传服务器。

## 音视频转换支持哪些格式？

视频格式转换支持导出 MP4、MOV、AVI、MKV、WebM。音频格式转换支持导出 MP3、WAV、AAC、M4A、FLAC。视频提取音频支持导出 MP3、WAV、M4A、AAC。处理过程使用本地 FFmpeg WASM 内核，文件不会上传服务器。

## 视频提取音频需要多长时间？

时间取决于视频大小、编码复杂度和当前设备性能。工具会在本地读取视频音轨并生成新的音频文件，长视频建议使用离线版并预留足够时间。

## 离线版可以完全断网安装和使用吗？

目标是满足安装和使用都完全离线。安装包会内置核心静态资源、PDF.js worker、FFmpeg WASM 和图标等资源。断网时广告位显示本地占位。

## 本项目提供 PDF 编辑吗？

不提供。本项目只提供 PDF 转图片，不提供 PDF 编辑、PDF 转 Word、PDF 转 Excel、PDF 文字修改、PDF 涂销、PDF 签名盖章、PDF 批注标注等能力。
