# 在线方案 A：精密白场

## 定位与信息架构

- 定位：面向大众用户的“清楚、可靠、一步一步可核对”工具站。
- 首页：品牌导航 → 价值说明 → 图片 / PDF / 文档 / 音视频 / OCR 五类工具目录 → 本地处理承诺。
- 工具页：顶部统一分类带 → 当前工具与面包屑 → 文件与预览主区 → 固定参数检查区。
- 导入采用单一主入口；选中文件后原位替换为文件摘要，不额外生成漂浮卡片。
- 1440px 为横向工作区；768px 改成纵向步骤；390px 完全取消常驻侧栏。

## 统一目录规范

- 顶部主导航只保留“在线工具”和“离线版”等产品入口，不按功能新旧拆分第二套工具入口。
- 五个用户分类固定为：图片工具、PDF 工具、文档工具、音视频工具、OCR 工具。
- 首页、分类带、面包屑、移动工具切换器和搜索结果必须使用相同分类名称。
- “离线批量”是低权重范围标签，只说明批量或目录输出能力；它不创建独立分类，也不暗示在线版已提供该能力。

## 颜色

| 角色 | 色值 | 用法 |
| --- | --- | --- |
| 页面 | `#F5F7FA` | 页面底色 |
| 表面 | `#FFFFFF` | 工具面板、对话框 |
| 内嵌面 | `#F1F5F9` | 预览占位、次级区 |
| 正文 | `#121826` | 标题与正文 |
| 次文 | `#667085` | 辅助信息 |
| 边框 | `#DCE3EB` | 常规分隔 |
| 强边框 | `#AEBCCC` | 聚焦、选中 |
| 主色/处理中 | `#1268FF` | 主操作、进度 |
| 成功 | `#168A48` | 完成 |
| 警告 | `#B96A00` | 等待、试用提醒 |
| 错误 | `#D63B3B` | 失败、危险操作 |

广告位保持中性 `#F7F8FA`，不与主操作竞争。

## 字体与排版

- 字体：`Microsoft YaHei UI`, `Segoe UI`, system-ui；不新增网络字体。
- 字阶：12 / 14 / 16 / 20 / 28 / 40px。
- 行高：小字 1.4，正文 1.6，标题 1.2。
- 字重：400 正文、600 控件和小标题、700 页面标题。
- 文件名单行省略，完整内容通过 `title` 或可访问描述提供。

## 尺寸与组件

- 间距：4 / 8 / 12 / 16 / 24 / 32 / 48px。
- 圆角：4 / 6 / 10px；只用于控件、容器和对话框。
- 控件高度：40px；移动端触控目标不小于 44px。
- 边框：1px；键盘焦点为 2px 主色外环，偏移 2px。
- 阴影：面板不用阴影；对话框 `0 18px 48px rgba(18,24,38,.18)`。
- 主按钮：蓝底白字；次按钮：白底深字加边框；危险按钮只在取消/清除场景使用红色。
- 输入框：白底、清晰标签、错误信息紧邻字段；不以 placeholder 代替标签。
- 图标：复用项目现有 `lucide-react`，16/18px，1.5px 描边；不使用 emoji 或手绘 SVG。

## 状态语言

- 空闲：一个明确导入动作，并说明文件只在本机处理。
- 已选择：文件缩略图、文件名、大小、类型和“已读取”状态同层呈现。
- 处理中：蓝色进度、当前动作、取消按钮；不伪造剩余时间。
- 成功：绿色状态、真实结果名、下载结果和继续转换。
- 失败：红色原因区、重新选择和查看说明；不把失败藏在 toast。
- 支持作者：桌面居中对话框；说明自愿、不影响功能、不收集文件。

## 响应式与动效

- `≥1181px`：五类工具横向展开，完整工具目录使用居中分类面板，主工作区保持宽预览。
- `821–1180px`：参数移至预览下方，保持步骤次序。
- `≤820px`：隐藏桌面导航和分类带，顶部显示“当前工具 / 切换工具”；切换器沿用同一五分类。
- `≤480px`：单列；按钮可满宽；390px 无常驻工具栏、无横向滚动。
- 动效：反馈 120ms、面板 180ms、对话框 240ms；`cubic-bezier(.2,.8,.2,1)`。
- `prefers-reduced-motion` 下关闭位移动画，只保留即时显隐。

## 实现风险

- 难度：低—中。最接近当前浅色结构，主要工作是重组移动端和收敛样式层。
- 风险：如果继续沿用全局重复 token，局部视觉可能互相污染；实施时应以在线壳根节点限定变量作用域。
