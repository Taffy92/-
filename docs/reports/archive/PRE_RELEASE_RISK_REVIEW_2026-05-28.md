# 发版前风险复审报告

## 结论

本次已经把前一版报告里的两个风险都处理掉了：

1. 桌面版窄窗口横向溢出
2. 桌面版与在线版的回归验证不一致

目前本地审查结果显示，没有新增的阻断性功能缺陷。

## 已修复内容

### 风险 1：桌面版窄窗口横向溢出

已处理。

- 将桌面版的任务空态、任务队列、历史面板外壳改成 `w-full min-w-0`
- 将任务表格统一收敛为容器内横向滚动，而不是让整页被宽表格撑开
- 重新构建并验证后，`375 / 768 / 1440` 三个视口下 `scrollWidth` 都与 `clientWidth` 一致

### 风险 2：桌面版与在线版的回归验证不一致

已处理。

- 回归脚本已改为按模式判断
- 桌面版检查折叠分组、桌面空态、无广告位
- 在线版继续检查单页工具、广告位与上传区
- PDF / Word / Excel 本地预览流程已重新验证可用

## 当前验证结果

- `next build`（桌面模式）通过
- `vitest`：51 / 51 通过
- `node scripts/run-playwright-static.mjs`：6 / 6 通过
- `node scripts/test-create-download-url.cjs`：通过
- 安全扫描未发现 `dangerouslySetInnerHTML`、`eval`、`new Function` 这类明显高风险注入点

## 仍需关注的部署前事项

1. 静态导出与安全头
   - 当前使用静态导出，安全头依赖 meta 回退与部署侧配置
   - 每次改动发布前都要复跑构建和浏览器回归

2. 离线安装包哈希同步
   - 重新打包后要继续同步 `downloads.ts`、`SHA256SUMS.txt`、发布说明和第三方 Notices
   - 这是当前仓库里最容易遗漏的发布项

3. CloudBase 下载授权链路
   - `createDownloadUrl` 脚本已本地验证通过
   - 上线前仍应确认授权入口与静态资源路径没有发生漂移

## 结论建议

如果现在要继续走正式发布，当前这版可以作为发版候选。
我建议你先审查这份报告，再决定是否进入部署和上线。
