## 剩余实现风险

- 原型为静态任务状态，第三阶段若获准，需要在不复制处理逻辑的前提下绑定真实 React 状态。
- 移动固定主操作栏需要在 Safari / Chromium 移动视口、软键盘和安全区下复测。
- 真实裁切器、PDF 页数、媒体解码和 OCR 长文本可能改变高度与性能预算。
- 正式支持弹窗应沿用生产焦点陷阱；原型只覆盖初始焦点、标题关联、关闭和 Escape。
- Node 20 下的正式构建、截图和核心转换回归仍属于未来实施阶段门禁。

当前不存在阻断 A2 人工视觉审阅的 P0、P1 或 P2 原型问题。
