# 万能格式转换器 Windows 离线专业版用户指南

## 适合场景

离线专业版适合：

1. 需要断网处理文件。
2. 需要批量处理大量图片、文档、音频或视频。
3. 文件包含隐私内容，不希望上传服务器。
4. 在线版处理大文件较慢。
5. 需要固定输出目录和批量任务队列。

## 添加文件

进入离线专业版工作台后，先选择当前转换工具，然后点击预览区中的“选择文件”按钮。系统文件窗口支持单选，也支持 Ctrl/Shift 多选当前工具支持的文件。

不支持的文件会被跳过，界面会显示导入数量和跳过数量。

## 选择输出目录

点击“输出目录”后选择本地文件夹。处理完成后，结果文件会保存到该目录。

如果没有选择输出目录，软件会使用默认下载目录或应用默认输出目录。

## 批量处理

1. 在左侧选择支持批量的转换工具。
2. 点击“选择文件”，单选或多选当前工具支持的文件。
3. 设置输出格式和参数。
4. 点击开始处理。

批量类型会自动跟随当前工具，不需要单独进入“批量处理”功能页。

处理进度和成功/失败数量会在右侧状态区展示。

## 清空任务

如果切换工具或准备重新导入，点击顶部“清空任务”可重置当前文件、批量队列、结果和进度。

## 取消任务

处理中可点击“停止”。当前任务会尽量停止，后续任务不会继续执行。

## 下载结果

单文件处理完成后，可点击顶部“下载结果”保存转换后的文件。

批量任务会按当前输出目录保存结果；未选择输出目录时，软件使用默认下载目录或应用默认输出目录。

## 图片批量处理

支持图片尺寸调整、图片批量加水印和图片压缩。图片裁切需要逐张确认裁切框，仍按单文件处理。图片处理在本机完成，不上传服务器。

## PDF / Word / Excel 批量处理

支持 PDF 批量转图片、Word 批量转图片、Excel 批量转图片。复杂文档的视觉还原受原文件结构和本地渲染能力影响，重要文件请人工核对。

## 音频 / 视频批量处理

支持音频格式转换、视频格式转换、视频提取音频。

离线专业版保留 FFmpeg WASM 回退能力，并对白名单格式使用本地 sidecar FFmpeg 优先处理。

## sidecar 白名单格式优先

当前 sidecar 优先范围：

1. WAV 转 FLAC。
2. MP4、MOV、AVI、MKV、WebM 常用视频格式转换。
3. ffprobe 媒体信息读取。

其他音频格式转换、视频提取音频，以及不在白名单内的音视频容器或编码组合继续使用 FFmpeg WASM。

## 如何关闭 sidecar 优先

在设置中心关闭“使用本地 sidecar FFmpeg 优先处理白名单格式”。关闭后，白名单格式也会回到 FFmpeg WASM。

如果 sidecar 处理失败，可以关闭该选项后重试。

## 隐私说明

1. 文件内容不上传服务器。
2. 转换结果不上传服务器。
3. 批量任务状态仅在本机工作台展示。
4. 输出结果由用户主动下载或保存到本地目录。
5. 授权只控制桌面端继续使用，不接触用户处理文件。
