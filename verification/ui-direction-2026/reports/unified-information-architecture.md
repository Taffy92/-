## 统一命名规则

- 首页、工具目录、分类轨、面包屑、移动切换器和离线工作台只使用上表五个分类名称。
- 同一代码功能 ID 在目录中只出现一次。
- “离线批量”是能力范围标签，不是分类、页面或第二个功能入口。
- “离线版”仍可作为独立产品入口保留。
- “批量任务”与“输出与任务结果”是离线工作区视图，不复制上表工具。
- 当前代码没有持久化、跨会话或云端历史记录，因此视觉方案不虚构“历史记录中心”。

## 在线结构

1. 顶部产品导航：`首页 / 在线工具 / 使用教程 / 离线版 / 关于`。
2. 在线工具目录：五个统一分类。
3. 工具上下文：`在线工具 / 分类 / 当前工具`。
4. 移动端：顶部工具按钮或底部“选择工具”打开同一五分类面板。
5. 旧 `/local-tools` 路径在本阶段不删除、不改路由；视觉方案只停止把它解释成用户分类。

## 离线结构

1. 当前工具按钮持续显示 `分类 / 当前工具`。
2. 完整目录使用与在线版相同的五个分类和功能名称。
3. 批量任务、输出目录、本次任务结果是工作区能力。
4. 授权只表达本地试用、机器码、离线激活码或 `license.mrx`，不影响工具分类。
5. 离线工作台不显示在线 Header、Footer 或广告。
