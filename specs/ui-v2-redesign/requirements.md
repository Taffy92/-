# UI v2.0.0 重构需求

## 1. 目标

把设计师交付的在线深色方案和离线 Fluent 工作台方案落实到现有 Next.js 15 与 Tauri 项目中，同时保留 v1.1.0 已有的图片、文档、音视频、OCR、批量处理、离线输出和授权能力。

## 2. 用户故事

1. 作为在线用户，我希望快速找到工具并在浏览器本地完成处理，不需要登录或上传文件。
2. 作为手机用户，我希望导航、工具选择、参数和结果在小屏幕上仍可完整操作。
3. 作为离线用户，我希望一次导入多个文件，平铺查看每个文件并把结果写入明确的本地目录。
4. 作为试用用户，我希望清楚看到试用状态，并能通过离线授权码或授权文件继续使用。
5. 作为需要联系作者的用户，我希望能够复制作者微信号或发送邮件。
6. 作为网站访问者，我希望广告与文件处理区明确隔离，且离线版完全无广告。

## 3. 功能需求与验收条件

### R1 在线品牌与公共页面

- 当用户打开首页时，系统应展示设计师方案的深色非对称首屏、真实功能图谱、本地处理说明和离线版入口。
- 当用户使用桌面导航时，系统应提供首页、在线工具、增强工具、教程、离线版和关于入口。
- 当用户使用 390px 宽度设备时，系统应提供可开关的移动端菜单且不得横向溢出。
- 当公共页面展示产品能力时，系统应只描述当前代码已支持的格式和能力，不得固定伪造 WebGPU、内存或 OCR 准确率。

### R2 在线工具可用性

- 当用户进入基础工具或增强工具时，系统应继续使用现有真实处理函数，不得替换为模拟进度。
- 当用户选择文件时，系统应展示文件摘要、预览和适用参数。
- 当任务处于等待、运行、完成、取消或错误状态时，系统应提供清晰且可操作的反馈。
- 当浏览器能力不足、文件过大或内存不足时，系统应说明原因并建议调整参数或使用离线版。
- 工具操作区域不得渲染广告。

### R3 离线专业工作台

- 当桌面模式启动时，系统应展示浅色 Windows 生产力工作台，不渲染在线导航、页脚或广告。
- 当用户选择多个文件时，系统应平铺预览每个文件。
- 图片应展示缩略图；PDF、Word、Excel 应展示第一页缩略图；视频应展示首帧容器。
- 当用户处理批量任务时，系统应持续显示等待、处理中、成功、失败和总进度。
- 多页 PDF、Word、Excel 结果应写入同名子文件夹，批量结果不得回退为 ZIP 或 7Z。
- 当窗口宽度缩小时，系统应优先保留任务预览，并折叠或重排参数区域。

### R4 离线试用与授权

- 当桌面授权状态正在读取时，系统应展示与离线主题一致的加载状态。
- 当试用已结束、授权过期、授权无效或系统时间异常时，系统应展示对应原因、机器码、授权码输入和授权文件导入。
- 授权流程不得要求登录，也不得上传用户处理文件。

### R5 作者联系方式与赞赏

- 在线版“联系我们”和离线版“关于与支持”区域应展示作者微信 `___Skyblue` 和邮箱 `370298218@qq.com`。
- 联系信息应提供复制按钮，邮箱应提供 `mailto:` 链接。
- 赞赏入口应使用本地微信、支付宝二维码，并明确赞赏不代表购买或授权。
- 赞赏与离线授权应保持为两个独立流程。
- 在线工具区、广告附近和离线命令栏不得长期铺开展示联系方式。

### R6 广告与隐私

- 在线版只能保留百度联盟提供商和首页、教程两个白名单广告位置。
- 未配置或未审核通过百度广告时，生产页面应隐藏空广告容器。
- 项目广告配置、CSP、`ads.txt`、隐私政策、条款和测试中不得保留 Google 广告代码或域名。
- 离线构建不得包含广告 DOM、广告脚本或广告网络请求。
- 用户文件、Blob、ArrayBuffer、Canvas、OCR 内容和结果不得提供给广告脚本。

### R7 版本与更新日志

- 当 v2.0.0 UI 重构进入正式代码时，根项目、Web、Desktop、Tauri 和产品版本配置应统一为 `2.0.0`。
- 更新日志只应展示版本号、更新日期、原有功能和新增功能。
- 更新日志不得记录开发操作、命令、部署步骤或内部过程。

### R8 质量

- 在线版应在 1440×900、1280×720、768×1024 和 390×844 下无横向溢出。
- 离线版应在 1440×900、1280×720 和 1024×720 下可操作。
- 主要交互应支持键盘，焦点应可见，弹窗应有标题、关闭和 Esc 行为。
- 当用户开启减少动态效果时，系统应停用非必要动画但保留所有功能。
- 正式交付前，项目测试、隐私检查、网络检查、Web 构建、EdgeOne 构建和桌面打包检查应执行并记录结果。

## 4. 非目标

- 不增加登录、注册、会员或云端转换。
- 不增加图片或视频去水印。
- 不增加扫码支付自动授权。
- 不改变 Logo、授权私钥边界或用户文件本地处理原则。
- 不改造私有授权后台的业务逻辑。
