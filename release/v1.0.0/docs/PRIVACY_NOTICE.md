# 万能格式转换器隐私说明

更新日期：2026-05-25

## 本地处理原则

万能格式转换器的核心原则是：用户文件尽量在当前设备本地处理。

默认情况下：

1. 图片不上传服务器。
2. PDF 不上传服务器。
3. Word 不上传服务器。
4. Excel 不上传服务器。
5. 音频不上传服务器。
6. 视频不上传服务器。
7. 输出结果不上传服务器。
8. 任务历史不上传服务器。
9. 处理日志不上传服务器。

## 离线专业版

Windows 离线专业版支持断网安装和断网处理。安装完成后，核心转换和批量处理功能不依赖服务器。

任务历史、处理日志和输出结果保存在用户本机。

## CloudBase 下载授权

CloudBase 只用于离线专业版下载授权，不接触用户正在处理的文件、转换结果、OCR 文本、日志内容或本地路径。

## 广告说明

在线版可能展示第三方广告。广告组件与文件处理逻辑隔离，不接收用户 File、Blob、ArrayBuffer、Canvas 或转换结果。

## 用户责任

请只处理自己拥有合法权利的文件。涉及身份证件、合同、财务票据、商业秘密或其他敏感文件时，建议优先使用离线专业版并断网处理。

## 后续联网功能
