使用指南

第一次使用也能顺利完成。

从浏览器权限、文件选择到结果导出，所有说明都围绕实际操作。

快速开始

在线版适合单文件或少量文件快速处理。选择工具、打开文件、调整参数，然后下载结果。

选择打开在线工具目录按文件类型或用途找到需要的处理工具。
打开选择当前设备上的文件页面会先检查格式，不会自动上传文件内容。
处理确认参数并运行处理状态、预览效果和结果会在同一工作区展示。
保存下载转换结果关闭页面前确认文件已经保存到需要的位置。
当前是界面审阅稿，文件按钮会载入内置示例，不会读取真实文件。

本地处理与隐私

文件处理逻辑在浏览器环境中运行。在线站点不接收用户文件、Canvas、Blob、ArrayBuffer 或转换结果。

页面关闭后的状态

未下载的结果会随页面关闭而消失。浏览器不会把处理记录同步到账号，因为在线版不提供登录系统。

广告边界

广告容器与文件处理区域隔离，用户文件内容不会交给广告服务。

屏幕共享说明

截图功能只有在用户主动点击后才会请求浏览器权限。浏览器会展示可共享的标签页、窗口或屏幕。

停止共享

可以随时使用浏览器提供的停止共享按钮。停止后页面不会继续读取屏幕画面。

大文件处理建议

浏览器内存有限。处理大体积视频、长文档或超高分辨率图片时，建议关闭无关标签页并保留足够磁盘空间。

出现内存不足时

降低输出尺寸或清晰度，也可以改用 Windows 离线专业版处理大文件和批量任务。

何时使用离线版

文件夹导入、多文件队列、断网处理、敏感文件和大文件都更适合离线专业版。

Windows 离线专业版

把完整处理能力留在电脑里。

适合断网环境、敏感文件、大文件和批量任务。安装后提供 3 天本地试用，无需登录。
