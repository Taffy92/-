# 离线安装版说明

万能格式转换器离线版基于 Tauri 打包，面向 Windows 10/11 x64。

离线版安装包需要把网站构建产物、JS、CSS、PDF.js worker、FFmpeg WASM、图标等静态资源一起打进安装包。安装和使用均应支持完全断网场景，不依赖服务器，不需要登录账号，不上传用户文件。

离线版保留与在线版一致的核心功能：

- 图片裁切
- 图片尺寸调整
- 图片添加水印
- 图片压缩
- PDF 转图片
- Word 转图片
- Excel 转图片
- 视频格式转换：MP4、MOV、AVI、MKV、WebM
- 音频格式转换：MP3、WAV、AAC、M4A、FLAC
- 视频提取音频：MP3、WAV、M4A、AAC

离线版程序界面是独立的白色桌面工作台，不照搬在线站点首页。顶部用于选择当前工具、转换参数、清空任务、输出目录和下载结果；中部把文件选择与预览合并为同一区域，大号选择文件按钮支持单选和多选；右侧显示本地内核、任务进度和输出状态。多个文件会平铺显示缩略图，其中 PDF、Word、Excel 使用第一页作为缩略图，视频使用首帧容器。底部只保留“本地运行，保护隐私安全”和开发者信息。离线版不渲染在线广告容器，也不强制联网加载广告。

批量能力跟随当前选中的转换工具，不单独列为一个“批量处理”功能页。当前批量队列覆盖图片尺寸调整、图片添加水印、图片压缩、PDF 转图片、Word 转图片、Excel 转图片、视频格式转换、音频格式转换和视频提取音频；图片裁切仍按单张图片裁切框处理。

每次桌面批量转换会在选定输出目录中创建独立时间戳文件夹。图片压缩等多文件结果直接写入该文件夹；PDF、Word、Excel 逐页导出时创建同名子文件夹。离线版不使用 ZIP 或 7Z 汇总批量结果。

图片压缩目标大小包括 500KB、200KB、100KB、50KB、25KB。

离线专业版包含本地 3 天试用和离线激活码或授权文件机制。授权只控制桌面端继续使用，不引入登录、会员或云端转换，细节见 `docs/offline-license.md`。

本项目不提供 PDF 编辑、PDF 文字修改、PDF 涂销、PDF 签名盖章、PDF 批注标注等功能。
