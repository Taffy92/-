# 项目发布审查与部署记录

日期：2026-06-12

## 结论

离线版白色工作台、文件即预览、批量平铺预览和文件夹输出已完成。工作台右上角不再显示“添加文件”和“添加文件夹”，导入入口统一放在文件预览区域。转换、隐私、网络边界、授权和桌面端 Rust 测试均通过，`v1.0.0` 安装包、下载配置、SHA256 清单和线上对象已对齐。

## 本轮处理

- 离线版改为白色苹果风格工作台，选择文件区域同时承担预览功能。
- 多文件使用平铺缩略图；PDF、Word、Excel 显示第一页，视频显示首帧容器。
- 移除工作台右上角“添加文件”和“添加文件夹”，预览区只保留支持单选/多选的“选择文件”按钮，不再保留拖放入口或下方任务列表。
- PDF、Word、Excel 多页结果和批量结果统一写入独立文件夹，不再生成 ZIP 或 7Z。
- 单文件结果保留原文件名，只替换目标扩展名。
- 修复离线机器码获取时弹出 `wmic.exe` 窗口的问题，并保留本地试用、机器码、激活码和 `license.mrx` 校验逻辑。
- 机器码只在当前进程内缓存，不再信任用户可写的机器码文件或注册表缓存，避免机器绑定被复制或替换。
- 修复 PDF 转图片离线处理和桌面端输出目录打开逻辑。
- 第三方声明的内嵌数据不再包含安装包自身哈希，避免安装包哈希循环变化。
- 桌面构建会移除下载页和公开发布资料，并在打包前检查安装包哈希不得进入桌面产物，彻底阻断安装包自哈希循环。
- README、离线说明、FAQ、安装指南、发布说明和公开站点文档已同步。
