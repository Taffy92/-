# 万能格式转换器 v2.0.0 界面与功能升级实施计划

更新日期：2026-07-29  
目标版本：v2.0.0

## 一、升级目标

本次升级在不改变“文件本地处理、不上传用户文件、不增加登录和云端转换”的前提下，完成在线版与 Windows 离线版的整体界面升级，并正式接入第一批、第二批本地处理能力。

- 在线版：采用深色编辑式工业科技风格，强化专业感、功能发现效率和隐私说明。
- 离线版：采用浅色 Windows 生产力工具风格，强化批量任务、参数控制、预览和输出效率。
- 在线版只保留百度联盟广告接口；完全移除 Google 广告代码和配置。
- 在线版与离线版都增加自愿赞赏入口、微信与邮箱联系方式。
- 离线版不加载广告，不依赖联网使用转换功能。

## 三、功能落实范围

### 1. 原有功能

- 图片裁切、尺寸调整、水印和压缩
- PDF、Word、Excel 转图片
- 视频格式转换、音频格式转换、视频提取音频
- 离线批量处理、独立文件夹输出和本地授权

### 2. 新增图片功能

- JPG、PNG、WebP、BMP 格式转换
- 旋转和水平、垂直翻转
- EXIF 常用信息查看
- 图片元数据清理
- 图片合成 PDF

### 3. 新增 PDF 功能

- PDF 合并
- PDF 拆分和页面提取
- PDF 页面重排、删除和旋转
- PDF 文字或图片水印
- PDF 页码、页眉和页脚

### 4. 新增音视频功能

- 音视频裁剪
- 视频静音
- 视频指定时间截图
- 视频转 GIF
- 音频顺序拼接
- 音量调整、淡入和淡出

### 5. 新增 OCR 功能

- 图片和 PDF 本地 OCR
- 简体中文、英文、中英混合识别
- 导出 TXT
- 导出可编辑 Word
- 导出以页面图像保留视觉版式的 Word

可编辑 Word 不能承诺复杂表格、公式和多栏排版完全还原；原样 Word 以页面图像为主，优先保持视觉版式。

## 四、在线版界面结构

1. 全局导航：品牌、在线工具、增强工具、教程、离线版、关于和赞赏入口。
2. 首页首屏：本地处理主张、在线工具与离线版主操作、本地处理路径示意。
3. 功能图谱：按图片、文档、OCR、音视频组织真实能力。
4. 本地处理说明：选择、处理、预览、保存四步隐私边界。
5. 百度联盟广告位：首页和教程页为白名单位置。
6. 工具页：左侧功能导航、中央文件与预览、右侧参数、底部任务操作。
7. 联系与赞赏：弹窗展示本地二维码、微信号、邮箱和复制操作。

## 五、离线版界面结构

1. 顶部命令栏：品牌、当前工具、增强工具、赞赏入口和运行状态。
2. 参数与操作区：输出格式、质量、输出目录、开始、停止和下载。
3. 文件工作区：单文件预览或多文件平铺预览。
4. 运行信息区：进度、内核状态、Sidecar 状态、任务数量和结果。
5. 增强工具页：工具导航、文件工作区、处理参数三栏结构。
6. 授权页：机器码、申请文件、授权码和授权文件导入。
7. 底部状态栏：隐私状态、开发者、微信和邮箱。

## 六、广告与隐私边界

- 只允许在线版加载百度联盟广告。
- 离线构建不渲染广告容器，不允许百度或 Google 广告网络请求。
- 用户的 File、Blob、Canvas、ArrayBuffer、OCR 内容和转换结果不得进入广告脚本。
- Google AdSense 组件、环境变量、CSP 白名单和 `ads.txt` 已从当前实现删除。
- 百度广告位编号未配置时，生产页面不加载广告脚本。

## 十、发布阻断条件

出现以下任一情况时不得发布：

- 测试或构建失败。
- 在线版出现用户文件外传。
- 离线版出现广告请求或强制联网。
- 安装包未生成、哈希不一致或无法启动。
- 授权私钥、客户记录或 `.mrx` 授权文件进入公开产物。
- 二维码真机扫码目标不正确。
