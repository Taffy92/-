# 项目全面审查报告

审查日期：2026-05-22  
项目路径：`D:\万能格式转换器项目`  
审查范围：在线网页、离线 Tauri 软件、共享核心包、CloudBase 授权下载云函数、构建脚本、隐私与发布准备。

## 1. 当前结论

项目已经具备可运行 MVP 基础：Next.js 在线版可以静态构建，Tauri 离线版已有 Windows 安装包产物，图片、PDF 转图片、Word 转图片、Excel 转图片、视频转换、音频转换、视频提取音频等模块已经在代码层接入。本次未直接重构代码，只做审查和规划。

当前最需要优先处理的发布风险有四类：

1. 离线版 Tauri 配置存在中文乱码，影响安装包名称、发布者、窗口标题、版权和描述展示。
2. `pnpm audit --prod` 显示 `next@14.2.35`、`xlsx@0.18.5` 存在公开安全告警。
3. 在线版和离线版 UI 已可用，但离商业级工具还有差距，尤其是专业版批量任务、任务队列、结果管理、错误恢复和状态反馈。
4. Word/Excel 转图片目前属于浏览器端近似渲染，不是 Office 原生排版级还原，复杂文档需要在离线专业版引入更可靠的本地渲染方案。

## 2. 项目结构

核心目录：

- `apps/web`：Next.js 在线版，配置了静态导出，产物目录为 `apps/web/out`。
- `apps/desktop`：Tauri 离线版，复用 `apps/web/out`。
- `packages/image-core`：图片裁切、压缩、尺寸调整、水印等本地处理能力。
- `packages/pdf-core`：PDF.js 本地解析与 PDF 转图片。
- `packages/export-core`：Word/Excel 转图片、图片页合成、ZIP 打包。
- `packages/media-core`：FFmpeg WASM 音视频转换核心。
- `packages/ui`：共享 UI 和广告组件。
- `packages/shared`：文件类型、常量、命名、隐私文案等共享逻辑。
- `cloudbase/functions/createDownloadUrl`：统一下载口令模式的 CloudBase 云函数。

## 3. 功能状态

在线版当前保留轻量单文件处理方向，符合“简洁易用”定位。离线版已经通过 `surface=desktop` 分支扩展出批量处理入口，这是专业版差异化的正确方向。

已发现的能力边界：

- 图片压缩、尺寸调整、添加水印、裁切属于浏览器 Canvas/Worker 可控范围，适合在线版和离线版共同维护。
- PDF 转图片基于 PDF.js，适合本地处理，但加密 PDF、异常字体、超大页数仍要做明确提示和分批策略。
- Word 转图片目前只解析 `.docx` 的 `word/document.xml`，可处理基础段落和表格，无法准确还原复杂样式、页眉页脚、浮动图片、文本框、分栏。
- Excel 转图片基于 SheetJS 读单元格，再用 Canvas 绘制，适合简单表格，复杂格式、合并单元格、图表、条件格式和精细宽高无法完全还原。
- 音视频转换基于 FFmpeg WASM，在线版可用但受浏览器内存和线程限制；离线专业版建议增加更强的本地队列和资源限制。

## 5. 关键风险

| 优先级 | 问题 | 影响 | 建议 |
| --- | --- | --- | --- |
| P0 | Tauri 配置中文乱码 | 安装包元数据、窗口标题、发布者信息不专业 | 统一修复为 UTF-8，重新打包验证 |
| P0 | `next` 与 `xlsx` 安全告警 | 发布审核、企业用户信任、潜在安全风险 | 评估升级 Next 15；替换或隔离 SheetJS |
| P0 | FFmpeg WASM 许可证风险 | 商业发布可能触发 GPL 合规要求 | 明确 Notices、源码获取方式、或改用 LGPL/系统 FFmpeg 方案 |
| P1 | Word/Excel 转图片还原有限 | 用户对“格式转换器”的预期落差 | 在线版标注轻量预览，离线专业版引入更强本地渲染 |
| P1 | UI 专业感不均衡 | 影响转化、信任和付费授权 | 在线版简洁，离线版做商业级任务台 |
| P1 | 授权下载只有统一口令 | 管理简单但泄露后无法按用户撤销 | 下一阶段可升级为口令 + 下载次数/有效期/日志风控 |

## 6. 推荐方向

在线版继续定位为轻量、快速、无需登录的工具页；离线版定位为“专业批量转换软件”，突出批量处理、断网可用、本地文件安全、任务队列和更稳定的本地引擎。两者共享核心能力，但不要强行保持完全相同的信息架构：在线版应少而快，离线版应更专业、更具体。
