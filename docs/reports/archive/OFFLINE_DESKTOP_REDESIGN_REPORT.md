# 离线专业版界面整改报告

## 发现的问题

1. 左侧工具区只有平铺按钮，没有按图片、文档、音视频、批量进行明确分组，不符合高频办公的快速查找习惯。
2. 离线专业版没有独立预览区，PDF、Word、Excel、图片、音视频的处理对象不够直观。
3. 开始 / 停止 / 输出目录等操作按钮离预览和任务区太远，操作路径偏长，不利于办公室高频使用。
4. 整体视觉偏营销展示，离“国企、办公、政府内网工具”的简洁、稳定、低干扰风格还有差距。

## 已完成整改

1. 左侧导航改成分类式结构，明确拆成：
   - 图片工具
   - 文档工具
   - 音视频工具
   - 批量处理
2. 离线版新增独立预览区，支持：
   - 图片预览
   - PDF 首页预览
   - Word 首页预览
   - Excel 首表预览
   - 视频预览
   - 音频播放预览
3. 将开始 / 停止 / 输出目录 / 清空完成收拢到离预览区更近的位置，并做成更短的操作条，减少鼠标移动距离。
4. 头部改成更克制的工作台式信息层，弱化营销感，强化“本地处理、批量高效、简单易操作”的办公定位。
5. 保持原有功能逻辑、权限、隐私、本地处理原则、LOGO 图标、说明文档、许可证等内容不变。
6. 未改 CloudBase 部署流程，未重新发布线上版本。
