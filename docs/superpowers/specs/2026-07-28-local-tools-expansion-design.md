# 万能格式转换器 1.1.0 本地工具扩展设计

## 1. 目标

在不改变本地处理原则、隐私边界、授权模型和在线/离线产品定位的前提下，扩展现有图片、文档和音视频处理能力。

本次更新合并原计划的第一批和第二批功能，版本从 `1.0.0` 升级为 `1.1.0`。功能按四个模块开发和验收：

1. 图片格式、方向与元数据工具。
2. PDF 页面整理与生成工具。
3. 音视频快速处理工具。
4. 图片与 PDF 本地 OCR 工具。

本设计不包含 UI 推翻重做、去除水印、登录注册、会员、云端转换、云端历史记录、第三方文件上传或完整视频剪辑时间线。

## 2. 产品边界

### 2.1 在线版

- 处理在浏览器本地完成。
- 面向单文件、少量文件和轻量任务。
- 可以按需加载本站同源的 PDF、FFmpeg、OCR 运行资源。
- 不把用户文件、Canvas、Blob、ArrayBuffer、OCR 结果或转换结果上传到服务器。
- 保留现有广告位和在线文件大小限制。

### 2.2 离线版

- 断网时仍可使用本次新增功能。
- OCR 运行资源和必要语言包随安装包或受控本地资源包提供，不依赖第三方 CDN。
- 支持大文件、多个文件和批量队列。
- 多文件继续使用平铺预览。
- 批量结果写入独立输出文件夹。
- PDF 和 OCR 多页结果写入对应文件的同名子文件夹，不使用 ZIP 或 7Z 汇总。
- 不渲染在线广告容器。

## 3. 模块一：图片格式、方向与元数据

### 3.1 图片格式转换

输入格式：

- JPG/JPEG
- PNG
- WebP
- BMP

输出格式：

- JPG
- PNG
- WebP

复用现有 Canvas、图片加载、质量控制和 Blob 导出能力。在线版处理单张或少量图片；离线版加入批量模式并输出到独立文件夹。

### 3.2 旋转与翻转

第一版支持：

- 左转 90°
- 右转 90°
- 旋转 180°
- 水平翻转
- 垂直翻转

复用现有 Cropper.js 和 Canvas。旋转后根据实际画布交换宽高，避免裁掉边缘。导出格式和质量沿用图片工具的统一设置。

### 3.3 EXIF 查看与清理

查看以下常用元数据：

- 拍摄时间
- 相机和设备型号
- 软件信息
- GPS 经纬度
- 图片方向
- 图片尺寸

第一版提供“清除全部元数据”，不提供逐字段修改。导出时必须保持图片视觉方向正确，避免清除 Orientation 后出现旋转错误。

在线版支持单张查看和清理；离线版支持批量清理。元数据解析使用宽松许可证的本地 JavaScript 组件，所有数据只在当前设备中读取。

## 4. 模块二：PDF 页面整理与生成

### 4.1 图片合成 PDF

- 每张图片生成一个 PDF 页面。
- 支持“跟随图片尺寸”和“A4 适配”两种页面模式。
- A4 模式保持图片比例并居中，不拉伸。
- 支持调整图片顺序后生成 PDF。

### 4.2 PDF 合并

- 支持按用户排列顺序合并多个 PDF。
- 合并前显示文件顺序和页数。
- 加密、损坏或无法解析的 PDF 不进入结果，并显示明确原因。

### 4.3 PDF 拆分与页面提取

- 支持单页、范围和离散页码，例如 `1,3,5-8`。
- 支持每页独立 PDF。
- 支持选择页合并为一个新 PDF。

### 4.4 PDF 页面管理

- 页面缩略图排序。
- 单页或多页旋转。
- 删除选中页面。
- 导出重排后的 PDF。

### 4.5 PDF 水印、页码和页眉页脚

- 添加文字水印或图片水印。
- 支持位置、透明度、字号、颜色和旋转角度。
- 支持全部页面或指定页面范围。
- 添加页码时支持底部居中、左下和右下。
- 页眉页脚第一版只支持单行文本，不提供复杂模板。

文档模块使用 `pdf-lib` 负责 PDF 创建和修改，现有 PDF.js 继续负责预览、页数读取和页面渲染。加密 PDF 不尝试绕过密码保护。

## 5. 模块三：音视频快速处理

### 5.1 视频和音频裁剪

- 输入开始时间和结束时间。
- 允许通过预览播放器读取当前时间。
- 校验开始时间小于结束时间，且范围不超过媒体总时长。
- 在格式和编码条件允许时优先快速复制；需要精确裁剪时重新编码。

### 5.2 视频静音

- 删除视频中的所有音轨。
- 保持视频画面和原时长。
- 输出格式沿用视频转换工具支持的格式。

### 5.3 视频截图

- 从当前播放位置提取一帧。
- 输出 JPG、PNG 或 WebP。
- 离线版支持按固定时间间隔批量提取帧，并写入视频同名子文件夹。

### 5.4 视频转 GIF

- 设置开始时间、结束时间、宽度和帧率。
- 在线版限制为轻量短视频任务。
- 离线版允许较长片段，但显示预计输出体积提示。

### 5.5 音频增强工具

- 音频裁剪。
- 多段音频按顺序拼接。
- 音量调整。
- 淡入和淡出。

本模块复用现有 FFmpeg WASM 和离线 FFmpeg sidecar。离线命令继续使用白名单参数构造，不开放任意命令行输入。视频片段合并、完整时间线、字幕编辑和多轨混音不属于本次范围。

## 6. 模块四：图片与 PDF 本地 OCR

### 6.1 输入

- JPG/JPEG
- PNG
- WebP
- BMP
- PDF

### 6.2 PDF 识别策略

1. 使用 PDF.js 检查页面是否存在可提取文字。
2. 文字型 PDF 优先直接提取文字和位置，避免不必要的 OCR。
3. 扫描型页面渲染为高清图片后执行 OCR。
4. 混合型 PDF 按页选择直接提取或 OCR。

### 6.3 语言

第一版提供：

- 简体中文
- 英文
- 简体中文与英文混合

在线版从本站同源地址按需加载语言资源并缓存。离线版必须在断网状态下加载本地资源。

### 6.4 输出

- TXT：按页面和阅读顺序输出纯文字。
- 可编辑 Word：重建段落、分页、图片和基础表格。复杂表格、多栏、公式、特殊字体和竖排内容可能与原稿存在差异。
- 原样 Word：每个原页面按比例放入 Word，优先保持视觉版式；主要内容作为页面图像呈现，不承诺自由编辑。

OCR 不宣传百分之百准确。界面显示页级进度和低置信度提示。手写文字、复杂公式和严重模糊图片标记为有限支持。

### 6.5 批量规则

- 在线版以单文件识别为主。
- 离线版支持多个图片和 PDF 进入任务队列。
- 每个输入文件写入独立结果目录。
- PDF 的逐页中间结果和导出文件进入该 PDF 的同名子文件夹。

OCR 使用本地 WebAssembly/Worker 执行，Word 使用本地 DOCX 生成组件创建，不调用云端 OCR 或文档转换 API。

## 7. 代码边界

### 7.1 共享处理核心

- `packages/image-core`：格式转换、旋转、翻转和元数据清理。
- `packages/pdf-core`：PDF 读取、页面预览、页面选择和页面操作。
- `packages/export-core`：图片合成 PDF、OCR 结果导出 Word。
- `packages/media-core`：裁剪、静音、截图、GIF 和音频处理。
- 新增独立 OCR 核心包：语言资源管理、Worker 生命周期、识别结果和进度事件。

在线版和离线版调用同一组处理接口，仅在文件选择、批量队列、资源位置和结果保存方式上使用不同适配器。

### 7.2 界面代码

现有 `ToolsClient.tsx` 已承载多个工具。本次只把新增工具的状态和面板拆到对应模块，避免继续把所有新增逻辑集中到单一文件。不得借此重构无关页面或改变已确认的 LOGO、首页和隐私文案风格。

## 8. 错误处理

- 文件格式与声明不符时拒绝处理。
- 损坏或加密 PDF 显示具体原因。
- 没有音轨的视频执行“静音”时提示无需处理。
- 裁剪时间无效时不启动 FFmpeg。
- 浏览器内存不足或文件超过在线限制时引导使用离线版。
- OCR 资源加载失败时允许重试，不上传文件作为回退。
- 用户取消任务后终止 Worker 或 FFmpeg，并清理临时 Blob、对象 URL 和临时文件。
- 离线批量任务中单个文件失败不阻断其余任务，失败项保留错误信息。

## 9. 隐私与网络约束

- 用户文件和结果不得发送到第三方服务。
- 在线运行资源只能从本站同源静态路径加载。
- 离线版不得强制联网获取运行资源。
- 新增依赖必须登记许可证和第三方声明。
- 网络检查必须确认云函数和授权后台不接收任何处理文件。

## 10. 测试与验收

### 10.1 图片

- 四种输入格式转换为 JPG、PNG、WebP。
- 旋转和翻转后尺寸、方向和透明通道符合预期。
- 清除 EXIF 后无法读取 GPS 和设备信息，图片方向仍正确。
- 离线批量结果位于独立文件夹。

### 10.2 PDF

- 合并后页数和文件顺序正确。
- 拆分、范围提取、删除、旋转和重排结果正确。
- 图片生成 PDF 时不拉伸。
- 水印、页码和页眉页脚只出现在指定页面。
- 加密和损坏 PDF 返回可理解的错误。

### 10.3 音视频

- 裁剪结果时长在允许误差内。
- 静音结果不包含音轨。
- 截图时间点和输出格式正确。
- GIF 时长、宽度和帧率符合设置。
- 音频拼接顺序、音量和淡入淡出正确。
- 在线 WASM 和离线 sidecar 对同一组样例均可完成处理。

### 10.4 OCR

- 图片、文字型 PDF、扫描型 PDF 和混合型 PDF 均能识别。
- 中文、英文和中英混合样例可导出 TXT。
- 可编辑 Word 能打开并包含对应页文字。
- 原样 Word 的页数和视觉顺序与输入一致。
- 断网状态下离线版 OCR 可用。

### 10.5 发布检查

必须通过：

- `npm test`
- `npm run build:web`
- `npm run build:edgeone`
- `npm run check:privacy`
- `npm run check:network`
- `npm run package:desktop`

## 12. 实施顺序

1. 图片格式、方向和 EXIF。
2. PDF 创建、合并、拆分、页面管理和水印页码。
3. 音视频裁剪、静音、截图、GIF 和音频增强。
4. OCR、TXT 与双模式 Word 导出。
5. 统一执行隐私、网络、构建、离线打包和发布检查。
6. 同步版本号并按约定生成精简更新日志。

每个模块通过自身测试后再进入下一个模块，最终作为同一个 `1.1.0` 功能版本发布。
