# 万能格式转换器在线版与离线版 UI 重设计规格

日期：2026-05-30  
范围：在线版 Web 工具台、Windows 离线专业版工具台  
状态：已完成设计规格整理；Stitch 项目已创建，生成屏幕请求因工具超时未产出屏幕实例。

## 设计目标

1. 界面整洁干净，降低装饰和干扰。
2. 面向国企、政府内网、办公室高频使用场景，视觉要稳定、专业、易扫读。
3. 保证现有功能不减少、不改逻辑、不改变本地处理和隐私原则。
4. 在线版强调单文件轻量处理，离线版强调批量、断网、内网、高频处理。
5. 在线版保留广告位，但广告位不遮挡主流程；离线版不引入广告。

## 必须保留的功能边界

### 图片工具

- 图片裁剪
- 尺寸调整
- 添加水印
- 图片压缩

### 文档工具

- PDF 转图片
- Word 转图片
- Excel 转图片
- 文件上传后提供文档首页或首表预览

### 音视频工具

- 视频格式转换
- 音频格式转换
- 视频提取音频

### 离线专业版

- 批量处理队列
- 输出目录选择
- 失败重试和停止任务
- 日志导出
- 历史记录
- 本地处理，不上传服务器

## 在线版界面方案

### 视觉系统

- 背景：`#F5F7FA`
- 主面板：`#FFFFFF`
- 边框：`#D7E0EA`
- 主色：`#235C8F`
- 安全/成功色：`#2C7A62`
- 警告色：`#B7791F`
- 错误色：`#B42318`
- 字体：Microsoft YaHei UI / system sans
- 圆角：6px 到 8px
- 阴影：极轻，不使用大面积发光、霓虹、渐变球

### 桌面布局

1. 顶部导航
   - 左侧：Logo + 万能格式转换器
   - 中间：工具、下载离线版、使用帮助、隐私说明、许可证
   - 右侧：本地处理状态胶囊

2. 左侧分类导航
   - 宽度约 248px
   - 默认只展开当前分组
   - 分组使用下拉箭头
   - 图片工具、文档工具、音视频工具、离线批量

3. 中央工作区
   - 当前工具标题、支持格式、隐私提示
   - 文件拖拽上传区
   - 文件信息条
   - 预览区：图片、PDF、Word、Excel、视频、音频都要有对应预览状态

4. 右侧参数面板
   - 宽度约 300px
   - 输出格式、质量、页码、尺寸、媒体质量等按功能变化
   - “开始转换”“停止任务”靠近参数底部，同时在预览区上方显示任务状态
   - 完成后“下载结果”按钮必须突出且靠近结果预览

5. 底部状态条
   - 当前文件
   - 本地处理
   - 浏览器内存提示
   - 离线版批量入口

### 移动端布局

- 顶部简化为 Logo、当前模式、安全状态
- 分类导航变为折叠抽屉或顶部下拉
- 参数面板下移到预览区下方
- 主按钮固定在可见区域底部，不遮挡广告位

## 离线版界面方案

### 视觉方向

离线版应更像 Windows 专业办公软件，不像网页照搬。整体使用浅色、低对比、高密度但不拥挤的工作台。重点突出“导入文件、选择任务、预览确认、开始处理、查看队列、导出结果”。

### 桌面布局

1. Windows 标题栏
   - 左侧：Logo + 万能格式转换器 离线专业版
   - 中间或右侧：本地处理、断网可用、版本号
   - 右侧：窗口控制按钮

2. 左侧模块栏
   - 宽度约 220px
   - 四个一级折叠菜单：图片工具、文档工具、音视频工具、批量处理
   - 默认不全部展开，只展开当前模块
   - 分类项清晰显示，不把所有功能一次性暴露

3. 顶部操作条
   - 添加文件
   - 添加文件夹
   - 选择输出目录
   - 开始处理
   - 停止任务
   - 清空队列
   - 操作条位置固定在主工作区上方，适合高频点击

4. 中央主区
   - 上半区：文件预览
   - 下半区：任务队列表格
   - 表格列：文件名、任务类型、输出格式、大小、状态、进度、操作
   - 选中任务后预览和参数同步变化

5. 右侧参数与信息面板
   - 当前任务参数
   - 输出目录
   - 任务统计
   - 日志摘要
   - 安全状态

6. 底部状态栏
   - 转换引擎状态
   - CPU/内存轻量提示
   - 本地处理承诺
   - 历史记录入口

## 可用性验收标准

1. 375px、768px、1440px 宽度下无横向溢出。
2. 所有按钮具备 hover、focus、disabled、loading、success、error 状态。
3. 主流程 3 步内可完成：选择功能、添加文件、开始转换。
4. PDF、Word、Excel 上传后有预览状态，不出现空白区。
5. 在线版广告位不遮挡上传、参数、预览、下载按钮。
6. 离线版高频按钮始终在主工作区上方或右侧可见，不藏在页面底部。
7. 文本对比度满足 WCAG AA。
8. 不新增登录、会员、云端转换、API 控制台等功能。
