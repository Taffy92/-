# 离线安装版说明

万能格式转换器离线版基于 Tauri 打包，面向 Windows 10/11 x64。

离线版安装包需要把网站构建产物、JS、CSS、PDF.js worker、FFmpeg WASM、图标等静态资源一起打进安装包。安装和使用均应支持完全断网场景，不依赖服务器，不需要登录账号，不上传用户文件。

离线版保留与在线版一致的核心功能：

- 图片裁切
- 图片尺寸调整
- 图片添加水印
- 图片压缩
- PDF 转图片
- Word 转图片
- Excel 转图片
- 视频格式转换：MP4、MOV、AVI、MKV、WebM
- 音频格式转换：MP3、WAV、AAC、M4A、FLAC
- 视频提取音频：MP3、WAV、M4A、AAC

离线版程序界面是独立的专业工具箱，不照搬在线站点首页。工作台包含顶部命令栏、左侧分类工具、中央上传/任务队列、右侧参数面板，适合连续处理文件、查看批量状态和设置输出目录。离线版不渲染在线广告容器，也不强制联网加载广告。

批量能力跟随当前选中的转换工具，不单独列为一个“批量处理”功能页。当前批量队列覆盖图片尺寸调整、图片添加水印、图片压缩、PDF 转图片、Word 转图片、Excel 转图片、视频格式转换、音频格式转换和视频提取音频；图片裁切仍按单张图片裁切框处理。

本项目不提供 PDF 编辑、PDF 文字修改、PDF 涂销、PDF 签名盖章、PDF 批注标注等功能。
