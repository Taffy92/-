# TAURI_PERMISSION_REVIEW

生成时间：2026-05-24

本轮范围：只评估离线专业版 Tauri 权限，不在未完成回归验证前收窄权限，避免破坏输出目录选择、文件夹导入、D 盘路径、中文路径和批量写入能力。

## 当前权限用途

| 权限 | 当前配置 | 主要用途 | 发布风险 |
| --- | --- | --- | --- |
| `dialog.open/save/message/confirm/ask` | 开启 | 选择文件、选择文件夹、选择输出目录、显示本地错误提示 | 必要权限，风险较低 |
| `fs.readFile` | 开启 | 读取用户主动添加的图片、文档、音频、视频文件 | 必要权限 |
| `fs.readDir` | 开启 | 扫描用户选择的文件夹，导入支持的文件类型 | 必要权限 |
| `fs.writeFile` | 开启 | 将转换结果写入用户选择的输出目录 | 必要权限 |
| `fs.createDir` | 开启 | 输出目录不存在时创建应用输出目录或批量任务子目录 | 必要权限 |
| `fs.copyFile` | 开启 | 后续结果管理、导出日志或复制结果文件可用 | 可保留，后续可再验证是否需要 |
| `fs.removeFile/removeDir/renameFile` | 关闭 | 不允许删除或重命名用户文件 | 已保持最小化 |
| `fs.scope` | `$HOME/**`、`$DESKTOP/**`、`$DOCUMENT/**`、`$DOWNLOAD/**`、`$PICTURE/**`、`$VIDEO/**`、`$AUDIO/**`、`C:/**`、`D:/**` | 覆盖 Windows 常见用户目录、D 盘项目目录、中文路径和用户选择输出目录 | `C:/**` 和 `D:/**` 偏宽，需要下一轮专项验证收窄 |
| `path.all` | 开启 | 解析 Windows 路径、文件名、扩展名、输出目录拼接 | 必要但偏宽，后续可改为按需 API |
| `shell.open` | 仅允许 `explorer` | 打开输出目录 | 必要权限，命令范围已限定 |
| `process.*` | 关闭 | 不允许退出、重启或启动外部进程 | 已保持最小化 |
| `updater.active` | 关闭 | 当前不启用自动更新 | 符合完全离线安装/使用要求 |

## 是否可以立即收窄

不建议在本轮直接删除 `C:/**` 和 `D:/**`。

原因：

1. 当前离线专业版需要支持用户从 D 盘、桌面、下载目录、文档目录、中文路径和带空格路径导入文件。
2. 文件夹导入和输出目录选择依赖用户选择后的真实 Windows 路径，过早收窄可能导致“选择成功但读写失败”。
3. 本项目当前使用的 Tauri 配置仍以静态 `fs.scope` 为主；若要做到“用户选择目录后动态授权”，需要针对当前 Tauri 版本做专项验证，不能在发布 P0 修复轮中盲目改动。
4. 冒烟测试明确要求不要扩大权限，也不要破坏 D 盘路径和中文路径。本轮没有扩大权限，仅保留现状并记录风险。

## 建议的后续收窄方案

下一轮可以单独做 `TAURI_PERMISSION_HARDENING_ROUND`：

1. 验证当前 Tauri 版本是否支持用户选择目录后的动态作用域授权。
2. 如果支持，优先将 `fs.scope` 收窄到：
   - `$HOME/**`
   - `$DESKTOP/**`
   - `$DOCUMENT/**`
   - `$DOWNLOAD/**`
   - `$PICTURE/**`
   - `$VIDEO/**`
   - `$AUDIO/**`
   - 用户通过系统对话框选择的目录
3. 如果不支持动态授权，至少在 UI 和发布说明中明确：软件只处理用户主动添加的文件和选择的输出目录，不会上传文件，不会扫描系统目录。
4. 增加自动化测试：D 盘路径、中文路径、带空格路径、输出目录写入、文件夹导入都必须通过后再收窄。

## 发布说明建议

当前离线专业版为本地转换工具。软件需要本地文件读写权限，用于读取用户主动添加的文件、扫描用户选择的文件夹、并把转换结果写入用户选择的输出目录。软件不会上传图片、文档、音频、视频或转换结果；CloudBase 仅用于下载授权，不接触用户处理文件。

## 本轮结论

本轮不修改权限配置。当前权限偏宽但未新增；在没有完整验证动态授权和 Windows 路径兼容性前，直接收窄会带来发布风险。建议下一轮在干净 Windows 10/11 虚拟机中做权限收窄专项验证。
