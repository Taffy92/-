# 第二阶段视觉方向评审

本报告只评审视觉方向、信息架构和实现风险。所有原型均为独立审查材料，没有接入现有页面、组件、路由或转换逻辑。

## 信息架构修订摘要

- 统一目录采用图片工具、PDF 工具、文档工具、音视频工具、OCR 工具五个分类，共 24 个去重后的真实功能。
- 顶部产品导航只保留“在线工具”和“离线版”等产品入口，不再按功能新旧建立第二套入口。
- “离线批量”只作为低权重适用范围标签；批量任务和输出结果只作为离线工作区视图。
- `/local-tools` 等现有路径没有修改或删除，本轮只修订视觉方案中的用户认知结构。

### 在线 A 修订

- 首页从三类摘要改为五类完整任务入口。
- 工具页分类带统一为五分类，并补充 `在线工具 / 图片工具 / 图片裁切` 面包屑。
- 390px 顶部工具按钮打开同一五分类面板；桌面和移动不再有第二套功能入口。

### 在线 B 修订

- 图标轨固定为五个真实分类；当前抽屉只显示音视频工具。
- 原扁平工具列表改为“当前分类 + 浏览全部分类”。
- 底部“选择工具”与桌面目录共用同一清单，离线批量范围以克制标签表达。

### 在线 C 修订

- 首页从三项原则说明改为五类任务入口。
- 顶部当前工具增加 PDF 分类面包屑，“切换工具”打开五分类目录。
- 三步流程仍只组织当前转换，不再承担功能分类。

### 离线 A 修订

- 左栏改成五分类折叠导航，只展开当前图片工具。
- 删除应用区中的第二套工具入口，增加“批量任务”和“输出与任务结果”工作区入口。
- 顶部当前工具按钮可以打开完整五分类目录。

### 离线 B 修订

- 左侧继续只做任务状态和队列，不把任务筛选误作工具分类。
- 顶部显示 `音视频工具 / 视频格式转换`，点击打开统一目录。
- 批量队列是当前工具能力，不形成新的功能专区。

### 离线 C 修订

- 左侧从十个旧工具的扁平编号改为五分类编号。
- 宽窗口展开当前文档分类的 Word / Excel 工具，1120px 折叠分类文字。
- 批量任务和输出结果作为工作区视图，不复制具体工具。

## 在线版三方向

### A：精密白场

- 核心气质：清楚、可靠、面向大众。
- 结构差异：工具分组从永久侧栏改为桌面横向分类带；文件、预览、参数按工作顺序排列。
- 导入：单一导入入口，选择后原位变为文件摘要。
- 参数：桌面固定检查区；平板和手机移到预览下方。
- 状态：五种状态均在工作区内联呈现，不依赖短暂 toast。
- 移动端：当前工具条 + “切换工具”动作，页面单列。
- 实现难度：低—中。
- 主要风险：若继续沿用重复的全局样式变量，局部样式可能串扰。

### B：夜间校准台

- 核心气质：专注、低眩光、适合长时音视频任务。
- 结构差异：56px 五分类图标轨 + 当前分类工具抽屉 + 主预览 + 右参数检查器。
- 导入：空闲时中央导入；选择后文件摘要、首帧和播放器连续排列。
- 参数：桌面右侧；移动端改成底部步骤。
- 状态：进度、取消、成功下载、失败重选都紧邻预览。
- 移动端：隐藏轨道、抽屉和右栏，底部四步导航替代。
- 实现难度：中—高。
- 主要风险：深色表单、二维码白场、广告位、系统自动填充均需单独校色。

### C：编辑式流程页

- 核心气质：克制、可阅读、适合文档与多页参数。
- 结构差异：完全取消工具侧栏，以 01 选择 / 02 参数 / 03 预览与开始组织页面。
- 导入：第一页缩略图和文件信息位于第一步。
- 参数：集中在第二步，不在多处重复。
- 状态：第三步原位切换为空闲、运行、成功或失败。
- 移动端：与桌面保持相同步骤结构，只做单列折叠。
- 实现难度：中。
- 主要风险：高频用户可能认为留白偏多；复杂工具需验证能否稳定归入三步。

## 390px P0：三种不同解法

| 方向 | 解决方式 | 为什么不再出现 212px 常驻侧栏 |
| --- | --- | --- |
| A | 顶部“当前工具 / 切换工具”条 | 桌面分类带在 `≤820px` 完全移除，工具选择成为按需动作 |
| B | 底部四步导航 | 图标轨、工具抽屉、右检查器在移动端全部隐藏，导航只保留任务步骤 |
| C | 全尺寸无侧栏 | 工具切换从一开始就在顶部，移动端只把三步纵向堆叠 |

三套 390px 截图均无水平滚动，主工作区宽度为完整视口内容宽度。

## Windows 离线版三方向

### A：清爽任务画布

- 核心气质：熟悉、低学习成本。
- 结构差异：左工具导航 / 中央平铺文件 / 右参数的标准三栏。
- 多文件：图片缩略图 3×2 平铺，状态直接显示在单元内。
- 参数：右侧固定；高级设置原位展开。
- 状态：单项与总进度并行，失败有重试，停止始终可见。
- 1120×720：压缩左右栏但保留三列预览。
- 实现难度：低—中。
- 主要风险：长文件名与右栏参数在最小宽度下需要严格截断规则。

### B：专业批处理台

- 核心气质：密集、专业、适合视频队列。
- 结构差异：左状态/队列索引 + 中央 2×3 首帧 + 右大预览 + 底部参数带。
- 多文件：平铺首帧与选中大预览并存，不退回列表或压缩包。
- 参数：底部横向带，减少右侧反复扫视。
- 状态：队列、缩略图和底栏三处同步。
- 1120×720：缩窄队列，仍保留两列缩略图和大预览。
- 实现难度：高。
- 主要风险：深色可访问性、视频预览性能和高密度键盘导航。

### C：紧凑三带式

- 核心气质：工程化、文档批处理、小窗口效率。
- 结构差异：顶部命令带 / 中央预览与参数 / 底部任务表。
- 多文件：1280 下 4×2 文档第一页缩略图；任务表集中显示页数、路径与重试。
- 参数：右侧 268px，1120 下压缩至 248px。
- 状态：缩略图提供即时状态，任务表提供完整结果。
- 1120×720：工具栏折叠为 56px 编号轨，预览改三列。
- 实现难度：中—高。
- 主要风险：三带高度预算严格，底部任务表与现有批量模型耦合较深。

## 离线硬边界核对

- 多文件均平铺，不以 ZIP / 7Z 代替预览或结果组织。
- 图片使用缩略图；文档使用第一页缩略图；视频使用首帧容器。
- 多页文档结果的规范均写为“批次独立文件夹 + 同名子文件夹”。
- 三套均展示输出目录、停止 / 取消、失败重试、高级设置和本地授权。
- 本地授权仅含 3 天试用、机器码、离线激活码和 `license.mrx`，无登录、会员或云端转换。
- 整个离线窗口不滚动；需要时仅任务区或表格内部滚动。

## 推荐结论

### 在线版首选：A 精密白场

它最直接解决当前移动端侧栏 P0，同时延续现有品牌的清洁可信感，落地风险最低。若后续确定文档工具是核心流量，可吸收 C 的“三步流程”作为 PDF / Word / Excel 工具页局部结构，但不建议把两套视觉语言混成一个折中稿。

### 离线版首选：A 清爽任务画布

它与当前离线壳的迁移距离最短，能优先解决多文件平铺、状态可见和 1120×720 信息拥挤。C 适合作为第二候选，尤其适合文档批处理；B 只有在明确把专业音视频用户作为首要人群时才值得承担较高实现成本。

## 暂不建议的组合

- 在线 B + 离线 A：品牌对比过大，需额外定义跨端品牌共性。
- 在线 C + 离线 B：一个重阅读、一个重监控，用户心智断裂最明显。
- 把 A/B/C 的颜色、导航和密度任意混合：会失去本轮方向比较的意义，也更容易产生“模板拼装感”。
