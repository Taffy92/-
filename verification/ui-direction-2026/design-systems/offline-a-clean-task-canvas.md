# 离线方案 A：清爽任务画布

## 定位与信息架构

- 定位：最容易上手的 Windows 批量转换工作台，接近文件管理器的认知。
- 顶部命令带：添加文件 / 添加文件夹 / 清空 → 当前工具 → 输出目录 → 开始 / 停止。
- 左侧 188px：图片工具、PDF 工具、文档工具、音视频工具、OCR 工具五类导航；只展开当前分类。
- 中央：所有文件平铺预览；图片用缩略图，PDF / Word / Excel 用第一页缩略图，视频用首帧容器。
- 右侧 288px：当前工具参数、输出目录、高级设置和开始按钮。
- 底部：总进度、当前文件、成功 / 失败 / 等待 / 已取消计数、打开输出目录。

## 统一目录规范

- 离线版与在线版共用五个基础分类名称及具体功能名称，不按专业版或开发批次拆分功能区。
- 当前分类在左栏展开；完整工具目录由顶部“分类 / 当前工具”按钮打开。
- “批量任务”和“输出与任务结果”属于工作区入口，不复制具体工具。
- 左栏小型“批量”标签只说明离线批量能力；本地授权仍是独立应用入口。

## 字体、密度与组件

- 字体：`Microsoft YaHei UI`, `Segoe UI`, system-ui。
- 字阶：11 / 12 / 14 / 16 / 20px；标题栏产品名 14px。
- 行高：1.35–1.5；数字使用等宽数字特性。
- 间距：4 / 6 / 8 / 12 / 16 / 20 / 24px。
- 圆角：3 / 5 / 8px；文件预览是平铺单元，不做悬浮大圆卡。
- 控件高度：34px；标题栏按钮 32px；可点击目标尽量达到 32×32px。
- 边框：1px；键盘焦点 2px 蓝色外环。
- 阴影：仅本地授权对话框 `0 18px 48px rgba(29,39,50,.22)`。
- 图标：复用 `lucide-react`，14/16px，1.5px 描边；状态必须同时有文字或可访问名称。

## 状态规范

- 空闲：中央居中导入入口，左右工作区保持稳定。
- 已导入：卡片网格平铺全部文件，不退回压缩包汇总。
- 处理中：单项进度、总进度、当前文件和停止入口同步可见。
- 成功 / 失败 / 取消：颜色、图标、文字三重区分；失败单项提供重试。
- 高级设置：右栏原位展开，不遮挡文件列表，不改变输出目录。
- 多页文档：在独立批次文件夹中创建同名子文件夹；界面明确显示输出目录。
- 本地授权：机器码、离线激活码、导入 `license.mrx`；不出现登录或会员入口。

## Windows 尺寸与动效

- `1280×820`：188 / 自适应 / 288 三栏，3×2 平铺预览。
- `1120×720`：左栏 168px，右栏 256px；保持 3×2，可缩短元数据但不隐藏状态。
- 最小窗口：1120×720；整个窗口不出现滚动条，只有中央任务区允许内部滚动。
- 动效：悬停 80ms、面板展开 140ms、对话框 180ms；`ease-out`。
- `prefers-reduced-motion` 下关闭位移，状态更新即时完成。

## 实现风险

- 难度：低—中。与现有离线浅色工作台结构最接近。
- 风险：1120 宽度下文件名、参数和状态容易互相争抢；需严格执行列宽和省略规则。
