# 下载页文案草稿

## 产品一句话介绍

万能格式转换器是一款支持图片、文档、音频和视频格式转换的本地处理工具，在线版轻量易用，Windows 离线专业版支持断网批量处理。

## 在线版入口文案

立即使用在线版  
无需安装，适合单文件或少量文件快速转换。文件在浏览器本地处理，不上传服务器。

## Windows 离线专业版下载文案

下载 Windows 离线专业版  
适合批量处理、敏感文件、大文件和断网环境。支持批量任务队列、输出目录选择、失败重试、预览区和下载结果。

## SHA256 校验说明

下载完成后，建议使用 SHA256 校验文件完整性。校验值可在下载页或 `SHA256SUMS.txt` 中查看。

## 隐私卖点

1. 文件默认在本机处理。
2. 不上传图片、文档、音频、视频或转换结果。
3. 离线专业版可断网使用。
4. CloudBase 只用于下载授权，不接触用户处理文件。

## 离线专业版功能列表

1. 批量导入跟随当前转换工具。
2. 图片尺寸调整、加水印和压缩。
3. PDF、Word、Excel 转图片。
4. 音频格式转换。
5. 视频格式转换。
6. 视频提取音频。
7. 输出目录选择。
8. 失败任务重试。
9. 右侧预览区和参数设置。
10. 下载结果。

## 已知限制

1. 在线版不开放批量任务队列。
2. 浏览器处理大文件可能受设备性能影响。
3. 未签名安装包可能触发 Windows SmartScreen 提示。
4. FFmpeg 相关许可证和专利事项在正式商业发布前仍建议人工复核。

## 开源许可证入口

下载页应提供“开源许可证”和“第三方组件声明”入口，用户可查看 FFmpeg、WebView2、Tauri、Next.js、PDF.js、ExcelJS 等组件说明。

请不要使用“绝对安全”“完全无风险”“已完成 FFmpeg 商业许可证最终复核”等表述。
