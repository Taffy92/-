# 离线方案 C：紧凑三带式

## 定位与信息架构

- 定位：兼顾文档批处理与小窗口效率的工程型工作台。
- 三带结构：顶部命令带 / 中央预览与参数带 / 底部任务明细带。
- 左侧工具轨：按编号列出五个统一分类，并在宽窗口中展开当前分类的真实工具。
- 中央预览：1280 宽度使用 4×2 平铺；Word / Excel / PDF 全部显示第一页缩略图。
- 右侧 268px：当前工具、输出格式、输出目录、高级设置和开始按钮。
- 底部任务表：文件名、页数、状态、输出路径、操作，集中处理失败重试与取消结果。

## 统一目录规范

- 编号 `01–05` 固定对应图片工具、PDF 工具、文档工具、音视频工具、OCR 工具。
- 当前分类下显示具体工具；1120px 只折叠分类文字，不创建第二套小窗口导航。
- “批量任务”和“输出与任务结果”是任务视图，不重复列出功能。
- 顶部分类按钮、左轨、完整工具面板和在线版使用相同名称；批量范围以低权重标签呈现。

## 字体、密度与组件

- 字体：`Microsoft YaHei UI`, `Segoe UI`, system-ui。
- 字阶：10 / 11 / 12 / 14 / 18px。
- 行高：1.3–1.45；任务表格固定行高 28px。
- 间距：3 / 6 / 8 / 10 / 12 / 16 / 20px。
- 圆角：2 / 3 / 5px；预览单元使用 2px。
- 控件高度：32px；工具轨行高 34px。
- 边框：1px；当前工具和当前文件使用 2px 青色标识。
- 阴影：仅模态框 `0 18px 50px rgba(35,48,54,.24)`。
- 图标：复用 `lucide-react`，14/16px，1.5px 描边；工具编号与文字始终保留。

## 状态规范

- 空闲：中央预览区显示导入入口，底部任务表保留表头以解释后续结构。
- 已导入：8 个文件直接平铺；小窗口允许预览区内部滚动，不退回列表或压缩包。
- 处理中：缩略图显示单项页数进度，任务表同步显示状态和输出。
- 成功 / 失败 / 取消：任务表提供明确文字；失败行显示重试，取消行可重新开始。
- 高级设置：右栏原位展开；不能把中央预览挤出窗口。
- 多页结果：输出到批次独立文件夹下的同名子文件夹；任务表展示实际路径。
- 本地授权：只提供机器码、离线激活码、`license.mrx` 导入和试用剩余时间。

## Windows 尺寸与动效

- `1280×820`：154px 分类轨 / 自适应 4×2 预览 / 278px 参数 / 约 188px 任务表。
- `1120×720`：工具轨折叠为 56px 编号轨，预览改为 3 列，参数缩至 248px，任务表约 160px。
- 最小窗口：1120×720；整个窗口无滚动条，预览区和任务表独立滚动。
- 动效：悬停 70ms、选中 100ms、展开 130ms、对话框 180ms；`ease-out`。
- 表格状态更新不使用位移动画，避免高频任务造成视觉跳动。

## 实现风险

- 难度：中—高。三带布局明确，但需精确处理 1120×720 的高度预算。
- 风险：底部任务表可能与现有批量状态模型耦合较深；路径列和长文件名必须严格省略并可查看全文。
