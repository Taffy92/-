# 离线方案 B：专业批处理台

## 定位与信息架构

- 定位：为高频视频 / 音频批量任务提供密集、可监控的专业控制台。
- 顶部命令带保持“导入—目录—开始—停止”单行。
- 左侧 210px：任务状态计数 + 当前队列索引，帮助快速定位失败和运行项。
- 中央上部：2×3 平铺首帧与单项进度。
- 中央右部：当前选中视频的大预览与元数据，不伪造额外分析能力。
- 底部参数带：输出格式、质量、视频尺寸、音频码率、高级设置。
- 状态栏：总进度、当前任务、结果计数和打开输出目录。

## 统一目录规范

- 顶部当前工具按钮显示“音视频工具 / 视频格式转换”，点击后打开五分类工具目录。
- 左侧任务概览只筛选当前队列状态，不承担功能分类，避免与工具目录形成两套导航。
- 图片、PDF、文档、音视频和 OCR 的名称与在线版保持一致。
- 批量与输出是工作台能力；“离线批量”范围标签不产生独立工具专区。

## 字体、密度与组件

- 字体：`Microsoft YaHei UI`, `Segoe UI`, system-ui。
- 字阶：10 / 11 / 12 / 14 / 18px；仅工作台标题使用 18px。
- 行高：1.3–1.45；时长、大小、进度使用等宽数字。
- 间距：3 / 6 / 8 / 10 / 12 / 16 / 20px。
- 圆角：2 / 3 / 4px；高密度工作区不使用大圆角。
- 控件高度：32px；标题栏按钮 30px。
- 选中项：黄色边框；运行进度：蓝色；结果状态不依赖同一颜色表达。
- 阴影：主工作区无阴影；授权对话框 `0 22px 60px rgba(0,0,0,.52)`。
- 图标：复用 `lucide-react`，14px，1.5px 描边；不能用图标替代文件状态文字。

## 状态规范

- 空闲：保留左侧队列与底部参数带，中央显示单一导入入口。
- 已导入：所有视频以首帧容器平铺，当前选中项同时在右侧大预览显示。
- 处理中：每项蓝色进度、总进度、当前任务；停止操作为红色描边。
- 成功 / 失败 / 取消：列表和缩略图两处一致；失败项提供单项重试。
- 高级设置：底部最后一格原位展开摘要，不弹出新的多层面板。
- 输出目录：顶部持续可见；结果按批次写入独立文件夹。
- 本地授权：暗色模态框，机器码、离线激活码、导入授权文件；无联网授权依赖。

## Windows 尺寸与动效

- `1280×820`：210px 队列 / 2 列缩略图 / 自适应大预览。
- `1120×720`：队列降至 168px，预览区维持两列缩略图和大预览，元数据压缩为两行。
- 最小窗口：1120×720；工作区固定填满窗口，列表和缩略图区各自内部滚动。
- 动效：悬停 70ms、选中 100ms、抽屉 140ms、对话框 180ms。
- 进度变化使用线性宽度动画 120ms；禁止循环发光、跳动和全屏转场。

## 实现风险

- 难度：高。需要重新组织队列、预览和参数区，并建立完整深色控件状态。
- 风险：信息密度最高，对键盘导航、深色对比、1120 宽度和视频性能要求也最高。
