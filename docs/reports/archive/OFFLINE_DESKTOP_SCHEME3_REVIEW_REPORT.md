# 离线专业版方案 3 改版审查报告

## 结论

已按方案 3 完成离线专业版的桌面化重构，并在此基础上做了进一步收敛，当前版本更偏向“国企 / 办公 / 政府内网工具”的桌面工作台风格。

本次只做本地修改和验证，**未部署到 CloudBase**。

## 本次整改内容

### 1. 重新组织功能分类

- 图片工具：裁剪、加水印、压缩、尺寸调整
- 文档工具：PDF 转图片、Word 转图片、Excel 转图片
- 音视频工具：视频格式转换、视频提取音频、音频格式转换
- 批量处理：离线队列、历史、导出

### 2. 改成更像桌面软件的布局

- 顶部增加桌面式命令栏，集中放置添加文件、添加文件夹、输出目录、开始、停止、清空、打开输出、导出日志
- 左侧改成树状分类导航，减少网页感
- 中间保留预览区，并补上 PDF / Word / Excel 的预览能力
- 右侧改成属性面板，集中显示当前参数、导出设置、任务信息、本地后端状态
- 下方保留任务队列、处理进度、结果与历史，但整体密度更接近办公软件

### 3. 保留约束

- 没有改 LOGO 图标
- 没有新增登录 / 注册 / 会员 / API 等功能
- 没有改变功能逻辑、权限、隐私、本地处理原则
- 说明文档、许可证、隐私说明等必要文件保持保留

## 这次重点修正的问题

1. 原来的离线版像网页，不像专业桌面工具。
2. 图片、文档、音视频分类不够明确。
3. 预览区缺失，PDF / Word / Excel 的操作反馈不完整。
4. 布局偏散，操作路径不够集中。
5. 顶部按钮区需要更像桌面命令栏，而不是网页按钮排布。

1. 顶部命令栏的按钮密度是否合适，开始 / 停止是否足够顺手
2. 左侧分类导航的层级是否够清晰
3. 右侧属性面板的长度和信息量是否符合办公场景
