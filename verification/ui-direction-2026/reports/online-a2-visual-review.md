# 在线 A2 视觉评审

## 结论

A2 保留在线 A 的信息架构和白场骨架，但已移除最明显的模板感。它不混入 B 的深色语言，也不把 C 的编辑式结构搬到全站。

对比审查图：`reports/online-a-vs-a2-review.png`。

## A 到 A2 的主要变化

| 区域 | 在线 A | 在线 A2 |
| --- | --- | --- |
| 首页标题 | 大字号、多行、视觉重量偏左 | 1440px 单行，44px，和右侧工作台平衡 |
| 背景 | 淡色科技网格 | 纯净浅灰页面与明确分隔 |
| 右侧展示 | 未选择文件的三步营销卡 | 已选择 PDF、文件信息、页数、参数和开始状态 |
| 五分类 | 大面积说明块 | 带序号的横向任务索引，无卡片堆叠 |
| 图片工具 | 上传、预览和参数按通用表单排列 | 真实裁切画布、预览工具栏、尺寸摘要与固定参数区 |
| 文档工具 | 未定义独立模板 | 页面缩略条、当前页预览、输出范围与结果组织 |
| 音视频工具 | 未定义独立模板 | 画面、播放、时间码、波形、范围和格式连续排列 |
| OCR | 未定义独立模板 | 原文件与识别结果并列，复制和导出靠近结果 |
| 390px 主操作 | 参数和按钮容易落到首屏以下 | 68px 固定任务栏持续显示状态与主操作 |
| 移动目录 | 工具列表较长，文字范围标签重复 | 搜索、五分类快速定位、两列工具和一次性范围说明 |

## 首页

- “文件转换，留在本机。”保持核心价值句，不再通过强制三行制造造型。
- 首屏同时提供价值、明确开始动作、本地处理事实、离线版边界和五分类入口。
- 真实 PDF 工作台使产品能力可核对，不使用虚构用户数、转化率或评价。
- 广告位保留且采用中性视觉，不模拟选择或下载按钮。

## 四类工作台

- 图片：以预览编辑为中心，参数不淹没裁切操作。
- 文档：围绕页面、范围、输出设置和结果组织。
- 音视频：把预览、时间范围和处理状态放在一起，同时保持浅色品牌壳。
- OCR：原文和结果并列，识别语言、导出、复制和下载均靠近结果。

四类模板共享 Header、五分类、面包屑、文件摘要、字段、按钮、状态、广告和响应式规则，但不强迫预览结构完全相同。

## 移动端

- 390px 无永久桌面侧栏，也没有第二套功能入口。
- 当前分类和工具通过顶部任务条进入同一目录。
- 图片预览压缩到合理比例；已选文件摘要保持单行截断。
- 主操作和当前状态固定在底部，选中、运行、成功、失败和取消均可见。
- 长参数页面可滚动，主操作不随参数长度消失。
- 所有可见按钮在自动检查中均达到至少 44×44px。

## 离线批量标识

目录顶部只解释一次 Windows 离线版批量能力。对应工具使用 8px 方框标记和可访问说明，不重复显示大面积文字标签，不形成筛选、分类或第二入口。

## 有意保留

- 当前 LOGO 与品牌名称。
- 首页、在线工具、使用教程、离线版、关于。
- 五分类与 24 个真实功能。
- 在线单文件、浏览器本地处理、离线批量产品边界。
- 广告位置、支持作者入口和二维码静区。
- `/local-tools` 等既有路径的现状；A2 原型不处理正式路由兼容。
