# Hallmark UI Polish Report

生成时间：2026-05-23

## 本轮目标

根据 `HALLMARK_UI_AUDIT_REPORT.md` 做小范围 UI 打磨，只处理 P1 和少量 P2 问题。  
本轮没有重做整体结构，没有修改核心转换逻辑，没有修改隐私网络守卫逻辑。

## 修改文件

1. `apps/web/src/components/tools/ToolsClient.tsx`

## 已解决的 P1 问题

1. 离线专业版 768px 下专业软件感下降  
   - 将离线专业版主布局调整为 `md` 宽度保留左侧导航。
   - 右侧参数面板在中等宽度下移动到主区域下方，避免变成网站式横向导航。

2. 离线专业版任务队列空状态不够真实  
   - 新增空任务队列面板。
   - 空状态加入三个动作入口：
     - 添加文件
     - 添加文件夹
     - 选择输出目录
   - 对尚未完整接入真实目录选择的入口标注“专业版批量任务中生效”，避免误导。

3. 无任务时开始按钮行为不清楚  
   - 无任务时禁用“开始处理”按钮。
   - 增加明确提示：“请先添加文件后再开始处理。”

4. 任务表格专业感不足  
   - 表格字段扩展为：
     - 文件名
     - 类型
     - 大小
     - 输出格式
     - 状态
     - 失败原因
     - 操作
   - 空任务状态会说明失败原因和操作将显示在队列中。

5. 右侧参数面板占位感较强  
   - 参数面板拆分为：
     - 当前参数
     - 导出设置
     - 批量设置
     - 高级设置
   - 未完全实装的桌面专业能力均标注“专业版批量任务中生效”。

6. 底部状态栏缺少真实状态词  
   - 新增状态映射：
     - 空闲
     - 处理中
     - 已暂停
     - 处理完成
     - 处理失败

## 已处理的 P2 问题

1. 在线版 375px 首屏文案压缩  
   - 缩短首屏主说明文案。
   - 移动端隐藏部分辅助格式说明，减少用户开始操作前的滚动成本。

2. 在线版功能横向滑动提示  
   - 移动端新增“左右滑动查看更多工具”提示。
   - 增加右侧轻微渐隐边缘，提示还有更多工具可滑动。

3. 下载按钮状态不够明确  
   - 未生成结果时，在下载按钮旁增加“处理完成后可下载。”提示。

4. 卡片圆角和阴影略微收紧  
   - 功能卡片、指标卡、工具区域卡片圆角收紧为更克制的 `rounded-xl`。
   - 保留原有主色和功能卡片可点击感，没有引入新主题、强渐变或营销动画。

5. 状态组件统一  
   - 新增统一 `StatusBadge`：
     - 等待中
     - 处理中
     - 成功
     - 失败
     - 已暂停
   - 进度文案统一为 `消息 · 百分比` 或批量任务的 `已处理 / 总数 · 百分比`。
   - 错误提示改为“发生了什么 + 下一步怎么做”的格式。

## 未处理建议

1. 没有开发真实文件夹选择和真实输出目录选择  
   原因：本轮只做 UI 微调，不改 Tauri 文件系统权限和批量任务核心逻辑。入口已保留并明确标注“专业版批量任务中生效”。

2. 没有重做在线版视觉主题  
   原因：审查报告建议是局部收紧，不建议换主题或重做结构。

3. 没有开发真实批量任务队列引擎  
   原因：这属于下一轮功能增强范围，本轮目标是发布前 UI 质量提升。

## 本地处理和隐私影响

本轮没有修改以下逻辑：

1. 文件解析与转换核心逻辑。
2. 图片、PDF、Word、Excel、音频、视频的本地处理逻辑。
3. `networkGuard` 隐私网络拦截逻辑。
4. CloudBase 下载授权逻辑。
5. 底部 `#ad-container` 广告容器位置。

结论：本轮 UI 打磨不影响“文件仅在本地处理，不上传服务器”的原则。
