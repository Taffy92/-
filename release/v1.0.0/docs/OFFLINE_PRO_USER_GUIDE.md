# 万能格式转换器 Windows 离线专业版用户指南

## 适合场景

离线专业版适合：

1. 需要断网处理文件。
2. 需要批量处理大量图片、文档、音频或视频。
3. 文件包含隐私内容，不希望上传服务器。
4. 在线版处理大文件较慢。
5. 需要固定输出目录和任务历史。

## 添加文件

进入离线专业版工作台后，选择对应功能类型，然后点击“添加文件”。可以一次选择多个支持格式的文件。

不支持的文件会被跳过，界面会显示导入数量和跳过数量。

## 添加文件夹

点击“添加文件夹”后选择一个目录。软件会扫描目录中的支持格式文件，并跳过不支持格式。

建议不要选择系统根目录或过深目录，避免扫描时间过长。

## 选择输出目录

点击“选择输出目录”后选择本地文件夹。处理完成后，结果文件会保存到该目录。

如果没有选择输出目录，软件会使用默认下载目录或应用默认输出目录。

## 批量处理

1. 选择批量处理类型。
2. 添加文件或文件夹。
3. 设置输出格式和参数。
4. 点击开始处理。

每个任务都有独立状态：等待中、处理中、成功、失败、已取消。

## 失败重试

失败任务会显示失败原因。确认参数或文件没有问题后，可以点击“重试”重新处理该任务。

损坏文件失败不会中断后续任务。

## 取消任务

处理中可点击取消。当前任务会尽量停止，后续任务不会继续执行。

## 打开输出目录

处理完成后可点击“打开输出目录”，快速查看结果文件所在位置。

## 打开单个结果文件

成功任务行可点击“打开文件”。如果结果文件不存在，会提示重新处理或检查输出目录。

## 导出处理日志

可导出处理日志用于排查问题。日志只记录脱敏路径、任务状态、失败原因和处理时间，不记录文件内容。

## 查看任务历史

离线专业版保存最近 100 条任务历史。历史记录只保存在本机，不上传服务器。

可以按成功、失败、取消筛选，也可以清空历史。

## 图片批量处理

支持图片压缩和图片批量加水印。图片处理在本机完成，不上传服务器。

## Word / Excel 批量处理

支持 Word 批量转图片、Excel 批量转图片。复杂文档的视觉还原受原文件结构和本地渲染能力影响，重要文件请人工核对。

## 音频 / 视频批量处理

支持音频格式转换、视频格式转换、视频提取音频。

离线专业版保留 FFmpeg WASM 回退能力，并对低风险格式使用本地 sidecar FFmpeg 优先处理。

## sidecar 低风险格式优先

当前 sidecar 优先范围仅限：

1. WAV 转 FLAC。
2. MP4 转 WebM。
3. ffprobe 媒体信息读取。

其他音视频格式继续使用 FFmpeg WASM。

## 如何关闭 sidecar 优先

在设置中心关闭“使用本地 sidecar FFmpeg 优先处理低风险格式”。关闭后，低风险格式也会回到 FFmpeg WASM。

如果 sidecar 处理失败，可以关闭该选项后重试。

## 隐私说明

1. 文件内容不上传服务器。
2. 转换结果不上传服务器。
3. 任务历史保存在本机。
4. 处理日志保存在本机。
5. CloudBase 只用于下载授权，不接触用户处理文件。
