# 离线界面方案 1：实现与视觉验收

日期：2026-08-02

## 本阶段范围

- 将离线版改造成 Windows 桌面生产力工作台：顶部命令栏、左侧分类与工具导航、中央任务预览、右侧参数检查器、底部队列状态栏。
- 工具切换改为应用内导航；授权状态在后台检查，不再用整页“正在检查授权状态”覆盖工作台。
- 开始转换前仍强制刷新授权状态，未改变试用、机器码、离线激活码或授权文件的权限模型。
- 多文件预览为固定三列的连续滚动网格，不限制为六个；所有导入文件都创建预览卡。
