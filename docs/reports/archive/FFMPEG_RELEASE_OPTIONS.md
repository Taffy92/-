# FFMPEG_RELEASE_OPTIONS

生成时间：2026-05-24

本文件按当前产品策略重新整理 FFmpeg 发布方案。当前阶段不执行在线版 FFmpeg 拆分，不删除在线版音视频功能。

## 方案 A：保留在线版和离线版 FFmpeg WASM，并补齐 GPL 说明

当前采用的短期方案。

| 维度 | 结论 |
| --- | --- |
| 是否适合商业发布 | 可作为短期过渡，但必须接受并处理 GPL 义务 |
| 许可证风险 | 高，`@ffmpeg/core@0.12.10` 声明为 `GPL-2.0-or-later` |
| 安装包体积影响 | 保持当前体积，继续包含约 30.85 MB FFmpeg WASM |
| 开发改动量 | 最小，主要是许可证、Notices、源码获取说明和界面入口 |
| 用户体验 | 在线版和离线专业版都保留音视频转换 |
| 是否影响完全离线 | 不影响，资源本地打包 |
| 是否影响在线版 | 在线版继续支持音频转换、视频转换、视频提取音频 |
| 是否影响离线专业版 | 不影响批量队列 |
| 是否需要源码获取方式 | 需要 |
| 推荐程度 | 当前短期推荐 |

## 方案 B：在线版保留音视频，但批量处理只做专业版入口

这是当前产品策略的落地方式。

| 维度 | 结论 |
| --- | --- |
| 是否适合商业发布 | 适合作为产品边界方案，但仍需 GPL 复核 |
| 许可证风险 | 仍然存在，因为在线版继续分发 FFmpeg WASM |
| 安装包体积影响 | 不减少在线版体积 |
| 开发改动量 | 低，只增加在线版批量入口和文档调整 |
| 用户体验 | 在线版保留轻量转换，专业版承接批量场景 |
| 是否影响完全离线 | 不影响 |
| 是否影响在线版 | 不影响在线版单文件音视频转换 |
| 是否影响离线专业版 | 不影响，专业版继续完整批量处理 |
| 是否需要源码获取方式 | 需要 |
| 推荐程度 | 当前最高推荐 |

## 方案 C：离线专业版 sidecar FFmpeg / LGPL 构建专项

中长期商业化重点方案。

| 维度 | 结论 |
| --- | --- |
| 是否适合商业发布 | 取决于 FFmpeg 构建许可证，LGPL 构建更适合作为商业路线 |
| 许可证风险 | 中到低，取决于是否启用 GPL/nonfree 组件 |
| 安装包体积影响 | 可能增加 50-150 MB |
| 开发改动量 | 高，需要 Tauri sidecar、参数白名单、进度解析和错误处理 |
| 用户体验 | 离线专业版性能和格式支持更好 |
| 是否影响完全离线 | 不影响，可完全离线打包 |
| 是否影响在线版 | 不要求移除在线版音视频 |
| 是否影响离线专业版 | 需要重构专业版音视频处理内核 |
| 是否需要源码获取方式 | 取决于构建许可证，通常仍需保留许可证和源码说明 |
| 推荐程度 | 长期推荐 |

## 方案 D：隐藏或标记音视频为实验功能

保守兜底方案，仅在无法完成许可证复核时考虑。

| 维度 | 结论 |
| --- | --- |
| 是否适合商业发布 | 最保守 |
| 许可证风险 | 如果不分发 FFmpeg 资源，风险明显下降 |
| 安装包体积影响 | 可减少 FFmpeg WASM 体积 |
| 开发改动量 | 中等 |
| 用户体验 | 音视频用户体验下降 |
| 是否影响完全离线 | 不影响其他功能 |
| 是否影响在线版 | 会削弱在线版功能 |
| 是否影响离线专业版 | 会削弱专业版功能 |
| 是否需要源码获取方式 | 如果仍分发 FFmpeg，则仍需要 |
| 推荐程度 | 当前不推荐 |

## 当前推荐

1. 当前阶段采用方案 B：在线版保留音视频转换，批量处理只作为离线专业版入口。
2. 不执行在线版 FFmpeg WASM 拆分。
3. 不删除在线版音频转换、视频转换、视频提取音频。
4. 不破坏离线专业版批量队列。
5. 继续保留 FFmpeg / GPL / 源码获取说明。
6. 下一阶段可以进入 sidecar FFmpeg / LGPL 构建技术方案设计。
