# UI 重新设计计划

审查日期：2026-05-22  
目标：在线版保持简洁易用，离线专业版提升到商业级工具质感。

## 1. 设计原则

在线版：

- 一个页面完成主要操作，不增加复杂后台感。
- 文件选择、功能选择、参数设置、预览、下载结果形成清晰路径。
- 保持轻量、安静、可信，不堆砌营销文案。
- 强调“本地处理，不上传服务器”。

离线专业版：

- 更像商业级桌面工具，而不是网页直接套壳。
- 强调批量任务、队列、任务状态、失败重试、输出目录、处理记录。
- 增加专业参数但保持默认配置可直接使用。
- 首页不做营销页，打开即进入工作台。

## 2. 在线版界面规划

建议结构：

1. 顶部导航：品牌、在线工具、下载专业版、教程、关于。
2. 首屏工具区：左侧功能卡片，右侧文件添加区或当前任务区。
3. 文件添加区：放在功能卡片下方或右侧主工作区，避免挡住功能选择。
4. 参数区：根据所选功能动态出现，选项全部中文化，格式名保留英文。
5. 预览区：图片类强预览，PDF/Office 类展示第一页或页数摘要，音视频展示文件信息。
6. 底部广告：统一放入 `<div id="ad-container">`，不遮挡操作按钮。

重点改进：

- 功能卡片继续保留“突出可按式”，但应加入明确的选中态、可用态、不可用态。
- 开始任务、取消任务、下载结果三个按钮使用更醒目的主次关系。
- 上传区域不要漂浮在右上角，应进入主流程位置。
- 移动端功能卡片改为两列或横向滚动，文件添加区放在功能选择后。

## 3. 离线专业版界面规划

建议使用“左侧导航 + 中央任务台 + 右侧参数/结果”的桌面软件布局：

- 左侧导航：所有功能、使用教程、关于我们、隐私政策、使用条款。
- 中央任务台：文件列表、批量任务队列、进度、失败原因、重试按钮。
- 右侧参数面板：输出格式、质量、尺寸、输出目录、命名规则。
- 底部状态栏：离线可用、当前版本、任务数量、内存提示。

离线专业版功能分组：

- 图片工具：裁切、尺寸调整、添加水印、压缩、批量压缩、批量加水印。
- 文档工具：PDF 转图片、Word 转图片、Excel 转图片、批量文档转图片。
- 音视频工具：视频格式转换、音频格式转换、视频提取音频、批量转换。
- 结果管理：打开输出目录、重新处理失败项、清空任务、导出日志。

## 4. 视觉规范

建议设计 Token：

- 背景：`#F6F8FB`
- 主色：`#0EA5E9` 或 `#0284C7`
- 强调色：`#14B8A6`
- 文本主色：`#0F172A`
- 文本次色：`#64748B`
- 边框：`#E2E8F0`
- 卡片圆角：在线版 16px，离线版 10px 到 12px
- 按钮高度：桌面 40px 到 44px，移动端 46px 到 50px

不要使用过度渐变、大面积发光、复杂装饰图形。工具类产品更重要的是稳定、清楚和可预期。

## 5. 可用性验收

- 375px、768px、1440px 三个宽度不横向溢出。
- 主流程 3 步以内：选功能、加文件、开始处理。
- 错误信息必须告诉用户下一步怎么做。
- 离线版批量任务支持暂停、取消、失败重试。
- 任何广告位不得遮挡文件添加、开始处理、下载结果按钮。
