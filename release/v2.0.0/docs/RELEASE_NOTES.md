# 万能格式转换器离线专业版 v2.0.0 发布说明

更新日期：2026-07-29

## 原有功能

- 图片裁切、尺寸调整、添加水印和图片压缩
- PDF、Word、Excel 转图片
- 视频格式转换、音频格式转换和视频提取音频
- 离线批量队列、独立文件夹输出和本地授权

## 新增功能

- 图片格式转换、旋转翻转、EXIF 查看与元数据清理
- 图片合成 PDF、PDF 合并拆分、页面重排旋转
- PDF 文字或图片水印、页码、页眉和页脚
- 音视频裁剪、视频静音、视频截图和视频转 GIF
- 音频拼接、音量调整、淡入和淡出
- 图片与 PDF 本地 OCR，导出 TXT、可编辑 Word 或原样 Word
- 在线版和离线版全新界面
- 微信与支付宝赞赏入口、作者微信号和邮箱

## 隐私原则

- 文件在当前设备处理，不上传到云端转换服务。
- 离线版不加载在线广告容器，可以断网使用转换功能。
- OCR 模型、PDF、图片和音视频处理资源随程序本地提供。
